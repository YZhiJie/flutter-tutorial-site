EP.02 doctor 全绿行动 · 开发环境搭建 ​

对应正文：阶段一 · 开发环境搭建

剧情回顾 ​

达达兴冲冲执行 flutter doctor，结果满屏红叉，哀嚎「装环境比写代码还难」。帧叔把环境搭建拆成「四站通关图」——SDK → doctor → IDE → 设备，并给出国内镜像配置；达达跟着「三步走」把项目跑了起来，被热重载的速度惊到。最后帧叔用一张 checklist 收束：环境一次配好，受益整个项目。

知识点拆解 ​

格 1 · 困境：满屏红叉 ​

flutter doctor 是环境体检工具，逐项检查工具链完整性。常见红叉与对策：

红叉项原因对策
Android toolchain许可未接受flutter doctor --android-licenses
XcodeCocoaPods 缺失brew install cocoapods
Connected device无可用设备启动模拟器或连真机

红叉不可怕，它是导航而不是判决——每一条都告诉你下一步做什么。

格 2 · 揭秘：四站通关图 ​

环境搭建的本质是按顺序通关四站：

  1. Flutter SDK：下载 stable 渠道，把 bin 目录加入 PATH
  2. doctor 体检：逐项修绿
  3. IDE 插件：VS Code 装 Flutter 扩展（自动带 Dart 扩展），或 Android Studio 装 Flutter 插件
  4. 设备运行：模拟器 / 真机 / Chrome 任选其一跑通

国内开发者第 0 步是先配镜像，否则 SDK 与依赖下载慢到怀疑人生：

bash
export PUB_HOSTED_URL="https://pub.flutter-io.cn"
export FLUTTER_STORAGE_BASE_URL="https://storage.flutter-io.cn"

格 3 · 实证：三步跑起来 ​

bash
flutter create my_app   # 生成项目骨架
cd my_app
flutter run -d chrome   # 指定设备运行

运行中终端的三个核心快捷键：

  • r 热重载：保留应用状态，只刷新 UI——改界面时的日常
  • R 热重启：丢弃状态重新启动——改了全局状态/初始化逻辑时用
  • q 退出运行

格 4 · 结案：全绿 checklist ​

交付一份可对照的验收单：SDK 入 PATH、镜像生效、doctor 全绿、IDE 插件就位。四项全绿，才算真正「通关」——之后所有项目共享这套环境。

坑点清单 ​

本话坑点

  1. 安装路径带空格或中文：Windows 上装到 C:\Program Files\ 或中文目录，后续构建会报难以排查的错误，务必用纯英文无空格路径。
  2. 镜像变量配了没生效：写入 ~/.zshrc 后必须 source 或重开终端；在公司电脑上注意区分当前使用的 shell（zsh / bash）。
  3. 首次 Android 构建卡 Gradle：国内网络拉 Gradle 依赖慢，可将 android/build.gradle 仓库换为阿里云镜像，耐心等待首跑。

自测 3 题 ​

Q1：flutter doctor 报 Android licenses status unknown，应该执行什么命令？

查看答案

flutter doctor --android-licenses，然后一路 y 接受全部许可。

Q2：热重载（r）和热重启（R）的区别是什么？什么场景必须用热重启？

查看答案

热重载保留应用状态只重建 UI；热重启丢弃全部状态重新执行 main()。修改了全局变量初始化、initState 逻辑或依赖注入配置时，状态已经"脏"了，必须热重启才能生效。

Q3：为什么国内建议配置 PUB_HOSTED_URL 和 FLUTTER_STORAGE_BASE_URL 两个变量？

查看答案

前者是 pub 包仓库地址（flutter pub get 下载第三方包用），后者是 Flutter SDK 与引擎产物的存储地址（SDK 升级、引擎下载用）。两者是独立服务，都需要镜像加速。
