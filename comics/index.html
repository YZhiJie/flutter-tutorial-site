Flutter 漫画剧场 ​

把教程画成四格漫画：每话一幅 1200×840 SVG 原画 + 一篇讲解（剧情回顾 / 知识点拆解 / 坑点清单 / 自测题）。 视觉体系：深墨底 + 霓虹青/紫/品红 + 斜切光楔；三角色——达达（提问担当）、小薇（行动派）、帧叔（教授总结）。规范见仓库 comics/style-guide.md。

建议读法 ​

  1. 先看原画，跟着剧情把概念「看见」
  2. 再读讲解，把每一格落成机制与代码
  3. 最后回到对应正文章节深读，并在 DartPad 里亲手跑一遍
