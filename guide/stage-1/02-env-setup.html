开发环境搭建 ​

学习目标 ​

学完本章，你将能够：

  • 在自己的电脑上完成 Flutter SDK 安装与配置
  • 配置国内镜像，解决依赖下载慢的问题
  • 使用 flutter doctor 诊断并修复环境问题
  • 在 VS Code 或 Android Studio 中创建并运行第一个项目
  • 理解模拟器与真机调试的差异

安装 Flutter SDK ​

macOS ​

bash
# 1. 下载 SDK（以 stable 渠道为例）
cd ~/development   # 或你喜欢的目录
git clone https://github.com/flutter/flutter.git -b stable

# 2. 配置环境变量，写入 ~/.zshrc
export PATH="$HOME/development/flutter/bin:$PATH"

# 3. 生效并验证
source ~/.zshrc
flutter --version

Windows ​

  1. 从 Flutter 中文站 下载 stable 渠道的 zip 包
  2. 解压到无空格、无中文的路径（如 C:\flutter）
  3. 将 C:\flutter\bin 添加到系统环境变量 Path
  4. 新开终端执行 flutter --version 验证

路径禁忌

安装路径不要包含空格、中文或需要管理员权限的目录（如 C:\Program Files\），否则后续构建会出现难以排查的错误。

配置国内镜像 ​

Flutter 的 pub 仓库与资源托管在境外，国内建议配置镜像（写入 shell 配置文件后重新打开终端）：

bash
export PUB_HOSTED_URL="https://pub.flutter-io.cn"
export FLUTTER_STORAGE_BASE_URL="https://storage.flutter-io.cn"

镜像失效怎么办

社区镜像可能调整，如访问异常，可切换为高校镜像（如清华 TUNA、上交）或临时使用代理，以 flutter.cn 社区镜像页 的实时信息为准。

用 flutter doctor 体检 ​

bash
flutter doctor -v

典型输出与处理：

检查项常见问题解决方式
Flutter版本过旧flutter upgrade
Android toolchain未接受许可flutter doctor --android-licenses
Xcode（macOS）CocoaPods 未装sudo gem install cocoapods 或 brew install cocoapods
Chrome未安装Web 调试需要，安装 Chrome 即可
Connected device无设备启动模拟器或连接真机

安装 IDE ​

二选一即可（也都可以装）：

  • VS Code：安装 Flutter 扩展（会自动带上 Dart 扩展），轻量、启动快
  • Android Studio：安装 Flutter 插件，集成度高，自带模拟器管理器

VS Code 快捷键速记：F5 启动调试，Ctrl+F5 免调试运行，编辑后 Cmd/Ctrl + S 保存即触发热重载。

创建并运行第一个项目 ​

bash
# 创建项目（包名建议用反域名写法）
flutter create --org com.example my_first_app
cd my_first_app

# 查看可用设备
flutter devices

# 运行到指定设备（模拟器/真机/Chrome）
flutter run -d chrome        # 跑 Web 版
flutter run -d <设备ID>      # 跑移动端

运行后在终端里可用快捷键：

按键作用
r热重载（保留状态刷新 UI）
R热重启（重置状态重新启动）
q退出

模拟器与真机 ​

  • Android 模拟器：Android Studio → Device Manager 创建，建议 API 33+、开启硬件加速
  • iOS 模拟器：仅 macOS，open -a Simulator
  • 真机调试：Android 开启开发者模式与 USB 调试；iOS 需在 Xcode 登录 Apple ID 并信任证书（免费证书 7 天有效）

常见坑 ​

高频踩坑点

  1. flutter doctor 全绿但跑不起来：先 flutter clean 再 flutter pub get，多数缓存问题可解。
  2. Gradle 下载超时：国内网络首次构建 Android 极慢，配置镜像后仍需耐心；可在 android/build.gradle 将仓库替换为 maven { url 'https://maven.aliyun.com/repository/google' } 等镜像。
  3. iOS 报签名错误：用 Xcode 打开 ios/Runner.xcworkspace，在 Signing & Capabilities 选择自己的 Team。
  4. SDK 升级后项目报错：flutter clean && flutter pub get，仍不行则对比新版模板重建 android/ios 目录。

课后练习 ​

  1. 执行 flutter doctor -v，把每一项的状态记录下来，修复所有非绿项。
  2. 用 flutter create 创建项目，分别跑通 一个模拟器 和 Chrome 两个目标。
  3. 在运行中的终端里分别按 r 和 R，观察界面差异，用自己的话总结热重载与热重启的区别。
