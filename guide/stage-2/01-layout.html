布局系统 ​

学习目标 ​

学完本章，你将能够：

  • 使用 Row / Column / Expanded 搭建基础布局
  • 理解 Flex 模型（主轴 / 交叉轴 / 对齐 / 弹性系数）
  • 使用 Stack + Positioned 实现层叠效果
  • 用 Container / Padding / Align 做间距、边距、对齐
  • 看懂 Flutter 布局约束链：父 Widget 传约束 → 子 Widget 传尺寸 → 父 Widget 定位

Flutter 布局的一句话法则

约束向上传递，尺寸向下传递，定位由父 Widget 决定。 这是所有 Flutter 布局的底层逻辑。

Row / Column：一维排列器 ​

最常用的布局容器，水平排用 Row，垂直排用 Column。它们本质是 Flex 模型的实现。

运行示例
DartPad 运行环境将在滚动到此处时加载…

观察三种布局：

  • 上：Row + mainAxisAlignment.spaceAround——三个图标均匀分布
  • 中：Row + Expanded——红 1 : 绿 2 : 蓝 1 的比例分配
  • 下：Column + crossAxisAlignment.start——标题/副标题/正文左对齐
查看完整源码
dart
import 'package:flutter/material.dart';

// Row / Column / Expanded 布局基础
// Row = 水平排列，Column = 垂直排列
// Expanded + flex = 按比例分配剩余空间

void main() => runApp(MaterialApp(
      home: Scaffold(
        body: Column(
          children: [
            // 基础 Row
            Container(
              height: 80,
              color: Colors.blue.shade50,
              child: const Row(
                mainAxisAlignment: MainAxisAlignment.spaceAround,
                children: [
                  Icon(Icons.star, size: 32, color: Colors.amber),
                  Icon(Icons.favorite, size: 32, color: Colors.red),
                  Icon(Icons.thumb_up, size: 32, color: Colors.blue),
                ],
              ),
            ),
            const SizedBox(height: 16),
            // Expanded 按比例分配：1:2:1
            SizedBox(
              height: 100,
              child: Row(
                children: [
                  Expanded(flex: 1, child: Container(color: Colors.red)),
                  Expanded(flex: 2, child: Container(color: Colors.green)),
                  Expanded(flex: 1, child: Container(color: Colors.blue)),
                ],
              ),
            ),
            const SizedBox(height: 16),
            // Column + crossAxisAlignment
            Container(
              color: Colors.purple.shade50,
              padding: const EdgeInsets.all(12),
              child: const Column(
                crossAxisAlignment: CrossAxisAlignment.start,
                mainAxisSize: MainAxisSize.min,
                children: [
                  Text('标题', style: TextStyle(fontSize: 20, fontWeight: FontWeight.bold)),
                  SizedBox(height: 4),
                  Text('副标题文字', style: TextStyle(color: Colors.grey)),
                  SizedBox(height: 8),
                  Text('正文内容'),
                ],
              ),
            ),
          ],
        ),
      ),
    ));

Flex 模型：主轴与交叉轴 ​

Row 和 Column 共享同一个 Flex 模型，只是主轴方向不同：

Row:       Column:
主轴 → 水平   主轴 ↓ 垂直
交叉轴 ↓ 垂直   交叉轴 → 水平

关键属性（Row/Column 通用）：

属性作用常用值
mainAxisAlignment主轴对齐start / center / end / spaceBetween / spaceAround / spaceEvenly
crossAxisAlignment交叉轴对齐start / center / end / stretch / baseline
mainAxisSize主轴方向占多少空间min（紧贴子 Widget）/ max（撑满父容器）
textDirection / verticalDirection排列顺序LTR / RTL / up / down

Expanded 与 Flexible

  • Expanded = Flexible(flex: 1, fit: FlexFit.tight)——强制占满剩余空间
  • Flexible 更灵活：fit: FlexFit.loose 只占子 Widget 实际需要的空间，但不会溢出
  • flex 是比例权重，不是像素；flex: 2 就是 flex: 1 的两倍宽度

Stack：层叠布局 ​

Stack 允许子 Widget 在同一块区域内层叠摆放——类似 HTML 的 position: absolute。用 Positioned 指定位置。

运行示例
DartPad 运行环境将在滚动到此处时加载…

上方是 Stack + Positioned 实现的「角标」效果：灰色方块右上角叠一个红色 3。下方是 Column 里用 Expanded 撑满剩余高度的经典三段布局。

查看完整源码
dart
import 'package:flutter/material.dart';

// Flex 布局三件套：Row / Column / Stack
// Stack 允许子 Widget 层叠，Positioned 控制子 Widget 位置

void main() => runApp(MaterialApp(
      home: Scaffold(
        body: Column(
          children: [
            // Stack + Positioned 实现角标
            SizedBox(
              width: 120,
              height: 120,
              child: Stack(
                clipBehavior: Clip.none,
                children: [
                  Container(
                    decoration: BoxDecoration(
                      color: Colors.blue.shade100,
                      borderRadius: BorderRadius.circular(16),
                    ),
                    child: const Center(
                      child: Icon(Icons.shopping_bag, size: 48, color: Colors.blue),
                    ),
                  ),
                  Positioned(
                    top: -8,
                    right: -8,
                    child: Container(
                      padding: const EdgeInsets.symmetric(horizontal: 8, vertical: 2),
                      decoration: BoxDecoration(
                        color: Colors.red,
                        borderRadius: BorderRadius.circular(12),
                      ),
                      child: const Text('3',
                          style: TextStyle(color: Colors.white, fontSize: 12)),
                    ),
                  ),
                ],
              ),
            ),
            const SizedBox(height: 24),
            // Expanded 在 Column 内占满剩余高度
            SizedBox(
              height: 200,
              child: Column(
                children: [
                  Container(height: 40, color: Colors.amber),
                  Expanded(child: Container(color: Colors.orange)),
                  Container(height: 40, color: Colors.amber),
                ],
              ),
            ),
          ],
        ),
      ),
    ));

间距与对齐 ​

Flutter 里没有 CSS 的 margin/padding 区分——全靠 Widget 嵌套：

dart
Padding(
  padding: EdgeInsets.all(16),    // padding = 子 Widget 内部留白
  child: Container(
    margin: EdgeInsets.only(top: 8), // Container 的 margin 类似 CSS margin
    child: ...,
  ),
)

常用工具 Widget：

  • Padding(padding: EdgeInsets.all(8)) — 子组件四周留白
  • SizedBox(width: 16) — 透明间隔条（Row/Column 里最常见的间距工具）
  • Align(alignment: Alignment.centerRight) — 将子组件对齐到指定位置
  • Center = Align(alignment: Alignment.center) 的简写
  • Spacer(flex: 2) — Expanded 的子类，占满剩余空间但不显示任何内容（Row/Column 里撑空位的首选）

布局约束：核心法则 ​

Flutter 的布局引擎遵循「约束向上 → 尺寸向下 → 定位由父决定」：

① 父 Widget 给子 Widget 一组约束（Constraints），比如「宽度 0~400，高度 固定 200」
② 子 Widget 在约束范围内选择自己的尺寸并告知父 Widget
③ 父 Widget 根据子 Widget 的尺寸和对齐规则，把它放在自己坐标系的某个位置

高频布局错误

无界约束下的无限宽高：把 ListView 直接塞进 Column 里会报错——Column 给子 Widget 的垂直约束是无限（unbounded），但 ListView 必须有确定高度才能工作。解决方案：用 Expanded(child: ListView(...)) 把 ListView 的高度固定到 Column 的剩余空间，或者用 SizedBox(height: 300, child: ListView(...))。

常见坑 ​

高频踩坑点

  1. Row 内容溢出黄黑条：Row 的子 Widget 总宽度超过 Row 本身会出现黄黑警告条。解决方案：把可能长的子 Widget 包进 Expanded 或 Flexible，或让 Row 变成可滚动（用 SingleChildScrollView 包裹）。
  2. Column 直接塞 ListView 报错：如上所述，用 Expanded 包住 ListView。
  3. Stack 子组件超出边界被裁剪：默认 Stack 会裁剪溢出的子 Widget。想要不裁剪，加 clipBehavior: Clip.none。
  4. SizedBox.shrink() 与 SizedBox() 混淆：SizedBox.shrink() 是 width: 0, height: 0，常用于条件渲染隐藏某 Widget；空 SizedBox() 就是占 0×0 空间。

课后练习 ​

  1. 三分屏：用 Column + Expanded 做一个上中下三等分的屏幕布局，中间放一个 Flutter logo。
  2. 购物车角标：用 Stack + Positioned 实现「圆形头像 + 右上角红色数字角标」。
  3. 自适应列表：把一个 Column 里的 Text 列表改成 ListView，然后把 ListView 放进 Expanded，让整个页面可滚动。
  4. 约束链实战：把一个 Container(width: 500) 直接塞进手机宽度的 Column 里会报什么错？为什么？用 UnconstrainedBox 强制让子组件按自己的尺寸渲染看看效果。
