常用组件 ​

学习目标 ​

学完本章，你将能够：

  • 了解 Material Design 风格下 Flutter 提供的核心组件家族
  • 正确使用 Container / Text / Icon / Image / Button / Input
  • 掌握列表类组件（ListView / GridView / Sliver）的使用场景
  • 使用 Theme / ColorScheme 统一管理应用视觉风格

组件分类速查

Flutter 的 Material 组件按用途大致分这几组：容器类（Scaffold/AppBar/Card）、展示类（Text/Icon/Image）、交互类（Button/TextField/Checkbox）、列表类（ListView/GridView）、导航类（BottomNavigationBar/Drawer/TabBar）。

基础交互组件一览 ​

运行完整组件展示
DartPad 运行环境将在滚动到此处时加载…

代码包含：Text / Icon / TextField / Checkbox / Slider / ElevatedButton / TextButton / OutlinedButton。每一类都有对应的命名参数，建议对照源码查看。

查看完整源码
dart
import 'package:flutter/material.dart';

// 常用组件速查：Text / Icon / Image / ElevatedButton / TextField / Checkbox
// 每个组件都有配套的命名参数，按需组合

class WidgetShowcase extends StatefulWidget {
  const WidgetShowcase({super.key});

  @override
  State<WidgetShowcase> createState() => _WidgetShowcaseState();
}

class _WidgetShowcaseState extends State<WidgetShowcase> {
  bool _agree = false;
  double _slider = 50;
  final _controller = TextEditingController();

  @override
  Widget build(BuildContext context) {
    return ListView(
      padding: const EdgeInsets.all(16),
      children: [
        const Text('Text 组件',
            style: TextStyle(fontSize: 24, fontWeight: FontWeight.bold)),
        const SizedBox(height: 8),
        Text('你好 Flutter！',
            style: TextStyle(
                fontSize: 20,
                color: Colors.blue.shade700,
                fontStyle: FontStyle.italic)),
        const Divider(height: 24),
        const Text('Icon 组件',
            style: TextStyle(fontSize: 18, fontWeight: FontWeight.bold)),
        Row(
          mainAxisAlignment: MainAxisAlignment.spaceEvenly,
          children: [
            const Icon(Icons.home, size: 32, color: Colors.red),
            const Icon(Icons.settings, size: 32, color: Colors.green),
            const Icon(Icons.favorite, size: 32, color: Colors.pink),
            Icon(Icons.star, size: 32, color: Colors.amber.shade700),
          ],
        ),
        const Divider(height: 24),
        const Text('TextField 组件',
            style: TextStyle(fontSize: 18, fontWeight: FontWeight.bold)),
        TextField(
          controller: _controller,
          decoration: const InputDecoration(
            labelText: '输入你的名字',
            border: OutlineInputBorder(),
            prefixIcon: Icon(Icons.person),
          ),
        ),
        const SizedBox(height: 16),
        const Text('Checkbox 组件',
            style: TextStyle(fontSize: 18, fontWeight: FontWeight.bold)),
        CheckboxListTile(
          title: const Text('我已阅读并同意用户协议'),
          value: _agree,
          onChanged: (v) => setState(() => _agree = v!),
        ),
        const SizedBox(height: 16),
        const Text('Slider 组件',
            style: TextStyle(fontSize: 18, fontWeight: FontWeight.bold)),
        Slider(
          value: _slider,
          min: 0,
          max: 100,
          divisions: 10,

        const SizedBox(height: 16),

            style: TextStyle(fontSize: 18, fontWeight: FontWeight.bold)),

          children: [

                onPressed: _agree ? () {} : null, child: const Text('Elevated')),

          ],
        ),
      ],

  }

容器家族 ​

Scaffold：页面骨架 ​

每一个 Material App 的页面几乎都从 Scaffold 开始——它提供了一个完整页面的槽位：

dart
Scaffold(
  appBar: AppBar(title: Text('标题')),
  body: Center(child: ...),
  floatingActionButton: FloatingActionButton(onPressed: () {}),
  drawer: Drawer(...),
  bottomNavigationBar: BottomNavigationBar(...),
  backgroundColor: Colors.blue.shade50,
);

Container：万能盒子 ​

Container 是 Flutter 里使用频率最高的容器——一个 Widget 同时集 尺寸 / 背景 / 边框 / 内边距 / 外边距 / 对齐 于一身：

dart
Container(
  width: 200,
  height: 100,
  padding: EdgeInsets.all(16),
  margin: EdgeInsets.only(top: 8),
  decoration: BoxDecoration(
    color: Colors.white,
    borderRadius: BorderRadius.circular(12),
    border: Border.all(color: Colors.blue.shade200),
    boxShadow: [BoxShadow(color: Colors.black12, blurRadius: 8)],
  ),
  alignment: Alignment.center,
  child: Text('Hello'),
)

什么时候不用 Container

  • 只需要留白 → 用 Padding
  • 只需要间距 → 用 SizedBox
  • 只需要圆角背景 → 用 DecoratedBox
  • 多个独立属性的 Container 嵌套可以用单个 Container 合并

追求语义清晰优先于追求嵌套最少。

列表家族 ​

ListView 和 GridView 是移动端最常写的两类组件。核心差异：

组件用途特点
ListView.builder长列表懒加载，只构建可见项
ListView.separated带分隔线的列表比手写 Divider 简洁
GridView.count固定列数网格每列等宽，如商品列表
GridView.builder自适应列数支持不等尺寸的卡片

ScrollController

滚动监听、滚动位置、滚动到某项都需要 ScrollController。记得 dispose() 里释放，不然内存泄漏。

按钮家族 ​

按钮的 Material Design 语义在 Flutter 里有清晰的对应：

组件风格典型场景
ElevatedButton带阴影、填充色主操作（提交、确认）
FilledButton扁平、填充色ElevatedButton 的简化版，Flutter 3.0+ 推荐
TextButton无填充、有文字色次要操作（取消、链接）
OutlinedButton边框、无填充介于主要和次要之间
IconButton只有图标工具按钮（AppBar 上的设置）
FloatingActionButton圆形浮动按钮Scaffold 右下的主 CTA

按钮禁用只需把 onPressed 设为 null——Material 会自动给按钮加 disabled 样式。

主题与颜色：Theme / ColorScheme ​

Flutter 的主题系统让你一次配置、处处生效。ColorScheme 是 Flutter 3.0 引入的 Material 3 色彩系统：

dart
MaterialApp(
  theme: ThemeData(
    useMaterial3: true,
    colorSchemeSeed: Colors.deepPurple, // 从这一个颜色生成完整色板
    brightness: Brightness.light,       // 亮/暗模式
  ),
  darkTheme: ThemeData(brightness: Brightness.dark, ...),
  themeMode: ThemeMode.system,         // 跟随系统
)

使用主题色时别硬编码——用 Theme.of(context).colorScheme.primary 或 context.colorScheme.primary（3.2+ 新增扩展），主题切换时颜色自动跟着变。

常见坑 ​

高频踩坑点

  1. Image 加载失败出现红色 ErrorWidget：没配网络权限（AndroidManifest.xml 的 INTERNET）、URL 错、HTTPS 证书问题。可以加 errorBuilder 兜底。
  2. TextField 点击弹出键盘时内容被挡：给 Scaffold 加 resizeToAvoidBottomInset: true（默认就是 true），或用 SingleChildScrollView 包裹。
  3. ListView 里放 StatefulWidget 状态丢失：给列表项加唯一的 Key（如 ValueKey(item.id)），帮助框架在重建时正确识别每一项身份。
  4. 硬编码颜色值：Colors.red.shade400 比 Color(0xFFF44336) 清晰；更推荐用 Theme.of(context).colorScheme.error 等语义化颜色。

课后练习 ​

  1. 消息列表：用 ListView.separated 搭一个消息列表，每一项显示头像、名称、消息正文、时间戳，加圆角卡片背景。
  2. 图标网格：用 GridView.count 展示你喜欢的 20 个 Material Icon，每 4 列一行。
  3. 主题切换：做一个开关，点击后让整个 App 在亮/暗主题之间切换（需要用 StatefulWidget + MaterialApp 外层包一个 State）。
  4. 表单实战：用 TextField + ElevatedButton 搭一个登录表单，加输入校验（邮箱格式、密码长度 ≥ 6）。
