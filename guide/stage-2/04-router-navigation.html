路由与导航 ​

学习目标 ​

学完本章，你将能够：

  • 使用 Navigator 的 push / pop 进行命令式路由
  • 用 MaterialPageRoute 传递参数、接收返回值
  • 了解 go_router 等声明式路由框架，以及 Navigator 2.0 的概念
  • 使用 BottomNavigationBar / TabBar / Drawer 搭建多入口导航

核心概念

Flutter 的导航栈是一棵「后进先出」的页面栈——Navigator.push 压栈，Navigator.pop 出栈。MaterialApp、CupertinoApp、Router 都内置了 Navigator。

Navigator：命令式路由 ​

运行示例
DartPad 运行环境将在滚动到此处时加载…

示例演示：

  • MaterialPageRoute 直接指定页面类 push
  • routes 表注册命名路由，pushNamed 跳转
  • pop 回到上一页，pushReplacement 替换当前栈顶
查看完整源码
dart
import 'package:flutter/material.dart';

// Navigator：命令式路由——push / pop / pushNamed
// MaterialPageRoute 自动提供 iOS 右滑返回手势

void main() => runApp(MaterialApp(
      title: '路由演示',
      home: const HomePage(),
      routes: {
        '/second': (ctx) => const SecondPage(),
        '/third': (ctx) => const ThirdPage(),
      },
    ));

class HomePage extends StatelessWidget {
  const HomePage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('首页')),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            const Text('首页（HomePage）'),
            const SizedBox(height: 16),
            ElevatedButton(
              onPressed: () {
                // ① push：压栈新页面
                Navigator.of(context).push(
                  MaterialPageRoute(builder: (_) => const SecondPage()),
                );
              },
              child: const Text('push → SecondPage'),
            ),
            const SizedBox(height: 8),
            ElevatedButton(
              onPressed: () => Navigator.of(context).pushNamed('/third'),
              child: const Text('pushNamed /third'),
            ),
          ],
        ),
      ),
    );
  }
}

class SecondPage extends StatelessWidget {
  const SecondPage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('第二页')),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            const Text('SecondPage'),
            const SizedBox(height: 16),
            ElevatedButton(
              onPressed: () => Navigator.of(context).pop(),
              child: const Text('pop ← 返回'),
            ),
          ],
        ),
      ),
    );
  }
}

class ThirdPage extends StatelessWidget {
  const ThirdPage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('第三页')),
      body: Center(
        child: ElevatedButton(
          onPressed: () => Navigator.of(context).pop(),
          child: const Text('pop ← 返回'),
        ),
      ),
    );
  }
}

传参和返回值 ​

dart
// 传递参数：通过构造函数（推荐）或 Navigator 的 arguments
Navigator.push(context, MaterialPageRoute(
  builder: (_) => const SecondPage(data: someData),
));

// 接收返回值：push 返回 Future，pop 时传值
final result = await Navigator.push<String>(context, ...);
// 在 SecondPage 里：Navigator.pop(context, '用户确认了');

常用 Navigator 方法 ​

方法作用典型场景
push / pop压栈 / 出栈最常用
pushNamed / pushReplacementNamed命名路由跳转统一维护路由表时
pushAndRemoveUntil压栈并清掉之前的全部栈登录成功跳首页并清除登录页
popUntil出栈直到满足条件返回首页
canPop栈是否可出控制返回按钮是否显示

go_router：声明式路由（推荐生产用） ​

Navigator 2.0 引入了声明式路由，但直接用太繁琐，社区封装的 go_router 是目前最成熟的方案：

dart
final router = GoRouter(
  routes: [
    GoRoute(path: '/', builder: (_, __) => HomePage()),
    GoRoute(path: '/detail/:id', builder: (_, state) {
      final id = state.pathParameters['id']!;
      return DetailPage(id: id);
    }),
    GoRoute(path: '/login', builder: (_, __) => LoginPage()),
  ],
  redirect: (_, state) {
    final loggedIn = ...; // 查全局状态
    if (!loggedIn && state.path != '/login') return '/login';
    return null;
  },
);

// 使用：context.go('/detail/42'); context.push('/login');
MaterialApp.router(routerConfig: router);

核心优势：

  • URL 与路由同步——Web 深链、桌面端地址栏、Android 深链统一
  • 内置守卫（redirect）、嵌套路由、错误页
  • 与 Riverpod 配合可以实现依赖注入到路由参数

多入口导航 ​

移动端常见的底部导航、Tab 切换、抽屉菜单：

BottomNavigationBar ​

dart
Scaffold(
  body: IndexedStack(
    index: _currentIndex,
    children: const [HomePage(), DiscoverPage(), ProfilePage()],
  ),
  bottomNavigationBar: BottomNavigationBar(
    currentIndex: _currentIndex,
    onTap: (i) => setState(() => _currentIndex = i),
    items: const [
      BottomNavigationBarItem(icon: Icon(Icons.home), label: '首页'),
      BottomNavigationBarItem(icon: Icon(Icons.explore), label: '发现'),
      BottomNavigationBarItem(icon: Icon(Icons.person), label: '我的'),
    ],
  ),
)

IndexedStack 的好处

用 IndexedStack 切换页面时，所有子 Widget 始终保持在树里——切走再切回来不会重建、不会丢状态。如果只用 if (_currentIndex == 0) ... else if ...，切走的页面会被 dispose。

Drawer（侧边抽屉） ​

dart
Scaffold(
  drawer: Drawer(
    child: ListView(children: [
      const UserAccountsDrawerHeader(...),
      ListTile(title: const Text('设置'), onTap: () => Navigator.pop(context)),
    ]),
  ),
)
// 打开抽屉：Scaffold.of(context).openDrawer()

常见坑 ​

高频踩坑点

  1. Navigator.push 返回 null：如果页面不是被 pop 带回来，而是用户直接点返回键或 App 被杀，返回值就是 null。用 final result = await Navigator.push(...); if (result != null) { ... } 防御。
  2. 命名路由参数传递：Navigator.pushNamed(context, '/detail', arguments: someObject)，然后在目标页用 ModalRoute.of(context)!.settings.arguments 取。类型不安全，推荐直接用构造函数。
  3. IndexController 没在 dispose 释放：TabBarView / PageView 的控制器一定要 dispose。
  4. go_router 与 Navigator 混用：go_router 是 Navigator 2.0 的抽象层，不要同时混用 Navigator.push 和 context.go，可能导致路由栈混乱。

课后练习 ​

  1. 参数传值往返：首页 push 到第二页并传一个 User 对象，第二页编辑后 pop 回首页并把更新后的对象作为返回值带回来。
  2. 登录流程：实现「未登录访问受限页 → 自动跳登录页 → 登录成功 → pushAndRemoveUntil 清栈跳首页」的完整守卫。
  3. 底部导航 + 状态保持：实现三 tab BottomNavigationBar，用 IndexedStack，切 tab 后每个 tab 里的计数器状态都保持。
  4. go_router 迁移：把命令式的 MaterialApp 改造成 MaterialApp.router 模式，配 go_router 路由表，实现上述登录守卫的路由版本。
