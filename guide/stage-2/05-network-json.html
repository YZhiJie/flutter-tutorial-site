网络请求与 JSON ​

学习目标 ​

学完本章，你将能够：

  • 使用 dart:io HttpClient 或 http 包发起 GET / POST 请求
  • 手动解析 JSON（jsonDecode + Map 操作）与使用代码生成（json_serializable）
  • 处理请求生命周期中的状态（加载中 / 成功 / 失败）
  • 理解并处理网络层常见问题：超时、重试、错误码、取消请求

推荐栈

快速上手：http 包 + json_serializable + Freezed需要流式 / WebSocket / Mock 测试：dio + 拦截器 声明式 API 层：retrofit（基于 dio）

基础：dart:io HttpClient + http 包 ​

Flutter 里发起网络请求最底层的方式是 dart:io 的 HttpClient（DartPad 环境也可用），生产代码通常用更友好的 http 包。

运行示例（HttpClient，零依赖）
DartPad 运行环境将在滚动到此处时加载…

点「请求数据」后约 1 秒会从 jsonplaceholder.typicode.com 拉一个 Post 并展示。注意 HttpClient 需要手动 close()、以及 try-catch-finally 包裹。

查看完整源码
dart
import 'package:flutter/material.dart';

// 网络请求示例（DartPad 安全版）
// DartPad 浏览器环境不支持 dart:io 的 HttpClient，
// 这里用 Future.delayed 模拟请求延迟，同时展示完整的 UI 状态机写法。
// 真实项目用 package:http（pub.dev/packages/http）+ jsonDecode。

class _Post {
  final int id;
  final String title;
  final String body;
  _Post({required this.id, required this.title, required this.body});
  factory _Post.fromJson(Map<String, dynamic> j) => _Post(
        id: j['id'],
        title: j['title'],
        body: j['body'],
      );
}

// 模拟网络请求（真实项目里换成 http.get）
Future<Map<String, dynamic>> _fetchPost() async {
  // 模拟 1.5s 延迟，随机 1/4 概率抛异常（演示错误处理）
  await Future.delayed(const Duration(milliseconds: 1500));
  // ignore: avoid_print
  print('网络请求完成');
  return {
    'id': 1,
    'title': 'Flutter 异步编程入门',
    'body': 'Future 和 Stream 是 Dart 处理异步的两个核心类。'
        'Future 表示单次异步结果，Stream 表示连续事件流。',
  };
}

void main() => runApp(const MaterialApp(home: NetworkPage()));

class NetworkPage extends StatefulWidget {
  const NetworkPage({super.key});
  @override
  State<NetworkPage> createState() => _NetworkPageState();
}

class _NetworkPageState extends State<NetworkPage> {
  _Post? _post;
  String? _error;
  bool _loading = false;

  Future<void> _fetch() async {
    setState(() {
      _loading = true;
      _post = null;
      _error = null;
    });
    try {
      final raw = await _fetchPost();
      setState(() => _post = _Post.fromJson(raw));
    } catch (e) {
      setState(() => _error = '网络错误: $e');
    } finally {
      setState(() => _loading = false);
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('网络请求示例')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.stretch,
          children: [
            ElevatedButton(
              onPressed: _loading ? null : _fetch,
              child: Text(_loading ? '加载中...' : '请求数据'),
            ),
            const SizedBox(height: 16),
            if (_error != null)
              Text('❌ $_error', style: const TextStyle(color: Colors.red)),
            if (_post != null) ...[
              Text('#${_post!.id} ${_post!.title}',
                  style: const TextStyle(
                      fontSize: 18, fontWeight: FontWeight.bold)),
              const SizedBox(height: 8),
              Text(_post!.body),
            ],
            const SizedBox(height: 24),
            const Divider(),
            const Text('真实项目写法（import package:http）：',
                style: TextStyle(fontWeight: FontWeight.bold)),
            const SizedBox(height: 8),
            const Text(
              "final resp = await http.get(Uri.parse(url));\n"
              "if (resp.statusCode == 200) {\n"
              "  final data = jsonDecode(resp.body);\n"
              "}",
              style: TextStyle(
                  fontFamily: 'monospace',
                  fontSize: 12,
                  backgroundColor: Color(0xFFF5F5F5)),
            ),
          ],
        ),
      ),
    );
  }
}

http 包简化版 ​

dart
import 'package:http/http.dart' as http;

// GET
final resp = await http.get(Uri.parse('https://api.example.com/posts/1'));
if (resp.statusCode == 200) {
  final json = jsonDecode(resp.body);
}

// POST
final resp = await http.post(
  Uri.parse('https://api.example.com/posts'),
  headers: {'Content-Type': 'application/json'},
  body: jsonEncode({'title': 'Hi', 'body': 'World'}),
);

JSON 解析：手动 vs 代码生成 ​

手动解析（适合简单场景） ​

dart
class Post {
  final int id;
  final String title;
  Post({required this.id, required this.title});
  // 手动 fromJson
  factory Post.fromJson(Map<String, dynamic> j) => Post(
        id: j['id'] as int,
        title: j['title'] as String,
      );
  Map<String, dynamic> toJson() => {'id': id, 'title': title};
}

// 使用
final list = (jsonDecode(body) as List)
    .map((e) => Post.fromJson(e as Map<String, dynamic>))
    .toList();

json_serializable + build_runner（推荐生产用） ​

手写 fromJson / toJson 无聊又易错，json_serializable 在编译期生成这些代码：

dart
import 'package:json_annotation/json_annotation.dart';
part 'post.g.dart';

@JsonSerializable()
class Post {
  final int id;
  final String title;
  @JsonKey(name: 'body_text')  // 字段名不匹配时手动映射
  final String body;
  Post({required this.id, required this.title, required this.body});
  factory Post.fromJson(Map<String, dynamic> json) => _$PostFromJson(json);
  Map<String, dynamic> toJson() => _$PostToJson(this);
}

运行生成：flutter pub run build_runner build --delete-conflicting-outputs

Freezed

freezed 把不可变数据类 + json_serializable 打包，额外支持 copyWith、== 比较、hashCode、Union 类型（Result.success / Result.error）。写业务 Model 首选。

请求生命周期状态机 ​

任何异步请求在 UI 上都有四个状态：

idle → loading → success  ✅
           ↓
         error  ❌

手动实现很繁琐，常用封装：

  • FutureBuilder：根据 Future 状态切换子 Widget，适合单次请求
  • StreamBuilder：根据 Stream 状态重建，适合轮询 / SSE
  • 状态管理框架里的 AsyncValue（Riverpod）/ Bloc 的 Loading/Loaded/Error 状态类

高级：超时、重试、取消 ​

dart
// 超时
final client = HttpClient()..connectionTimeout = Duration(seconds: 10);
final request = await client.getUrl(uri).timeout(Duration(seconds: 15));

// 取消请求（用 CancelToken 或 stream 订阅取消）
// dio 里：
final token = CancelToken();
dio.get(url, cancelToken: token);
// token.cancel('用户取消');

// 自动重试（dio 用拦截器，http 包手动循环）
Future<T> retry<T>(Future<T> Function() fn, {int max = 3}) async {
  for (var i = 0; i < max; i++) {
    try { return await fn(); } catch (e) {
      if (i == max - 1) rethrow;
      await Future.delayed(Duration(seconds: i + 1));
    }
  }
  throw Exception('retry exhausted');
}

常见坑 ​

高频踩坑点

  1. 忘记处理 HTTP 非 2xx 状态码：404 / 500 时 http 包不会抛异常，response.statusCode 只是数字。必须手动判断后再解析 body。
  2. JSON 解析类型转换：jsonDecode 出来的数字都是 int 或 double，不会自动适配你 Model 里的类型。推荐 as int / as String 显式强转，运行时报错比隐式掉数据好。
  3. Android 明文 HTTP 被拒：Android 9+ 默认禁止明文 HTTP。方案：用 HTTPS，或在 AndroidManifest.xml 加 network_security_config。
  4. 请求泄漏：FutureBuilder 或 StreamBuilder 里发起请求，但用户离开页面时请求还在飞。用 CancelToken / 手动 close / 在 State 的 dispose 里取消。
  5. 并发请求阻塞 UI：网络请求必须在异步函数里 await（或 .then），同步调用会阻塞 UI 线程导致 ANR。

课后练习 ​

  1. Post 列表 + 详情页：首页用 ListView 展示 https://jsonplaceholder.typicode.com/posts，点某一项 push 到详情页展示完整 body。用手动 fromJson。
  2. 代码生成改造：把第一题的 Post 类用 json_serializable + build_runner 改造，生成 .g.dart 文件。
  3. 错误处理增强：给你的请求加超时（10s）和 3 次自动重试，网络失败时在 UI 上显示重试按钮。
  4. 请求取消：打开详情页后立刻发起一个延迟 5 秒的请求，在这 5 秒内返回首页——确认请求被取消且无内存泄漏。
