自定义 Widget 与 RenderObject ​

学习目标 ​

学完本章，你将能够：

  • 用 CustomPaint + CustomPainter 在 Canvas 上直接绘制图形
  • 理解 RenderBox 的布局职责：接收 constraints → 决定 size → 绘制 / 子节点布局
  • 区分三种自定义方式：组合（普通 Widget 嵌套）、CustomPaint、RenderObject
  • 看懂 Flutter 内部组件的实现思路（比如 Row 继承 FlexRenderObject）

什么时候需要 RenderObject

99% 的 UI 用组合 Widget 就够了。只有这几种情况需要 RenderObject：自定义布局算法（瀑布流、自定义 Flow）、性能极其敏感（跳过 Widget 重建）、需要直接操作 Canvas 绘制复杂特效。

CustomPaint：最简单的直接绘制 ​

CustomPaint 是写自定义图形的首选——给一个 CustomPainter，在 Canvas 上画就完事了。

运行示例（画一颗心）
DartPad 运行环境将在滚动到此处时加载…

这里的 HeartPainter 继承 CustomPainter，实现 paint(Canvas canvas, Size size) 方法，用 Path 画心形。shouldRepaint 返回 false 表示不会重复画（性能优化）。

查看完整源码
dart
import 'package:flutter/material.dart';

// CustomPaint + CustomPainter：直接在 Canvas 上画
// Flutter 内部很多装饰组件（ClipPath、Decoration）本质都是 CustomPaint

class HeartPainter extends CustomPainter {
  @override
  void paint(Canvas canvas, Size size) {
    final paint = Paint()
      ..color = Colors.red
      ..style = PaintingStyle.fill;

    final path = Path();
    final w = size.width;
    final h = size.height;
    // 画一个心形：从底部中间向上，左弧 + 右弧 + 闭合
    path.moveTo(w / 2, h);
    path.cubicTo(w / 2, h * 0.7, 0, h * 0.4, w * 0.3, h * 0.2);
    path.cubicTo(w * 0.5, 0, w * 0.5, 0, w / 2, h * 0.25);
    path.cubicTo(w * 0.5, 0, w * 0.5, 0, w * 0.7, h * 0.2);
    path.cubicTo(w, h * 0.4, w / 2, h * 0.7, w / 2, h);
    path.close();

    canvas.drawPath(path, paint);
  }

  @override
  bool shouldRepaint(covariant CustomPainter oldDelegate) => false;
}

void main() => runApp(MaterialApp(
      home: Scaffold(
        body: Center(
          child: CustomPaint(
            size: const Size(200, 200),
            painter: HeartPainter(),
          ),
        ),
      ),
    ));

Canvas 常用 API ​

API作用
drawCircle / drawRect / drawRRect / drawOval基本形状
drawPath任意路径（Path 有 moveTo / lineTo / cubicTo / arcTo）
drawLine直线
drawImage绘制图片（需先 decode）
drawParagraph文字（Flutter 3.10+ 推荐用 TextPainter）
clipRect / clipPath / clipRRect裁剪区域
save / restore状态栈（save 后可以 translate/rotate，restore 恢复）

性能细节

CustomPainter 要声明 shouldRepaint：返回 false 时，框架认为图形没变化，跳过 repaint。内部变化时返回 true，或继承 Listenable + 传给 CustomPaint 的 painter: 让自动监听。

RenderObject：深度定制 ​

当 CustomPaint 不够用（需要自定义布局逻辑），就要继承 RenderBox。步骤：

  1. 继承 RenderBox
  2. 重写 performLayout（根据 constraints 决定 size、布局子节点）
  3. 重写 paint（绘制内容）
  4. 如果有子节点，重写 visitChildren 等
dart
class HeartRenderBox extends RenderBox {
  @override
  void performLayout(Constraints constraints) {
    size = constraints.constrain(const Size(200, 200)); // 决定自己的尺寸
  }

  @override
  void paint(PaintingContext context, Offset offset) {
    final canvas = context.canvas;
    canvas.drawPath(heartPath(size), Paint()..color = Colors.red);
  }
}

RenderObject 的优势：

  • 跳过 Widget 层：不需要 rebuild 就能 repaint
  • 完全控制布局：可以实现 Row / Column 没有的布局算法
  • 性能最佳：Flutter 内部的 Row / Column / Stack / Container 最终都走到 RenderObject

什么时候不该用 RenderObject

RenderObject 一旦写出来，维护成本很高——Widget 热重载不会生效、调试起来也更难。优先 CustomPaint，实在不行再上 RenderObject。

进阶：RenderProxyBox 与 SingleChildRenderObjectWidget ​

如果只是想给已有的 RenderObject 加一点行为，比如让某个已有的 Widget 支持旋转，可以继承 RenderProxyBox（单生子 RenderObject 的基类）：

dart
class RotatedBox extends SingleChildRenderObjectWidget {
  const RotatedBox({super.key, required Widget child}) : super(child: child);
  @override
  RenderObject createRenderObject(BuildContext context) => _RotatedRenderBox();
}

class _RotatedRenderBox extends RenderProxyBox {
  // 重写 paint：在子节点外面包一层 Canvas.save / rotate / restore
}

常见坑 ​

高频踩坑点

  1. CustomPainter 的 shouldRepaint 返回错：返回 true 导致每帧都 repaint（性能差）；返回 false 导致图形不更新（功能错）。最好让 painter 继承 ChangeNotifier，数据变时 notifyListeners，CustomPaint 自动 repaint。
  2. performLayout 里忘了处理 unconstrained 约束：ListView 内的子 Widget 收到的是无限约束，直接 size = Size(200, 200) 会崩。用 constraints.constrain(...) 包裹。
  3. RenderBox 没有 dispose：RenderObject 没有 dispose 生命周期，清理资源要在 dispose 上一层（Widget 的 dispose）里做。
  4. Canvas 坐标原点：Canvas 的 (0,0) 是 CustomPaint / RenderBox 的左上角。如果要绘制偏移内容，先 canvas.save() → canvas.translate(x, y) → 绘制 → canvas.restore()。

课后练习 ​

  1. CustomPaint 仪表盘：用 Canvas 画一个环形进度指示——外圈圆弧 + 中心文字百分比，点击按钮进度 + 10%。
  2. 自定义 RenderBox 瀑布流：写一个简单的 RenderWaterfall——多个子节点按列排列，每列高度不固定，列数由外部参数决定。
  3. 路径动画：让 Canvas 上的一条路径随 AnimationController 逐帧绘制（drawPath + Path.combine 截取部分）。
  4. 对比性能：同一段心形绘制，分别用 CustomPaint 包 Widget 和用 RenderBox 包 Widget，在 DevTools 的 Performance 面板看帧耗时差异。
