动画体系 ​

学习目标 ​

学完本章，你将能够：

  • 理解 Flutter 动画三要素：AnimationController（时间轴） + Tween（值区间） + Curve（曲线）
  • 正确使用 AnimatedBuilder / AnimatedWidget 避免无谓重建
  • 掌握常用过渡动画：淡入淡出、位移、缩放、旋转、交错动画
  • 使用动画控制器、监听动画状态、在 dispose 里正确释放

动画性能核心

Flutter 动画本质是每帧重建 build 方法的 Widget 树。60fps 意味着每秒 60 次 build。正确使用 AnimatedBuilder 只重建必要子树，是动画流畅的关键。

动画三要素 ​

AnimationController：时间轴 ​

dart
final controller = AnimationController(
  vsync: this,                              // 谁在 tick（用 SingleTickerProviderStateMixin）
  duration: const Duration(milliseconds: 600),
  reverseDuration: const Duration(milliseconds: 400),
);

controller.forward();     // 0 → 1
controller.reverse();     // 1 → 0
controller.repeat();      // 循环（默认正向）
controller.repeat(reverse: true); // 循环（正反向交替）
controller.stop();        // 停在当前值
controller.reset();       // 回到 0

vsync 参数让动画 tick 与屏幕刷新率对齐，避免隐藏窗口时继续计算。State 里用 with SingleTickerProviderStateMixin 即可。

Tween：数值映射 ​

Tween 把 0~1 的动画值映射到你关心的范围：

dart
// 从 1.0 缩放到 2.0
final scale = Tween<double>(begin: 1.0, end: 2.0).animate(controller);
// 颜色从蓝变紫
final color = ColorTween(begin: Colors.blue, end: Colors.purple).animate(controller);
// 带曲线
final curved = Tween<double>(begin: 0, end: 1).animate(
  CurvedAnimation(parent: controller, curve: Curves.easeInOut),
);

Curve：缓动曲线 ​

常用曲线效果
Curves.linear匀速（几乎不用）
Curves.easeIn慢入快出（起步时缓动）
Curves.easeOut快入慢出（结束时缓动）
Curves.easeInOut慢入慢出（最常用的自然曲线）
Curves.bounceOut弹跳
Curves.elasticInOut橡皮筋

一个方块在缩放（1.0→1.4）和颜色（蓝→紫）上同时循环动画。使用 AnimatedBuilder 只重建依赖动画值的部分。

查看完整源码
dart
import 'package:flutter/material.dart';

// 动画三件套：AnimationController + Tween + CurvedAnimation
// 用 AnimatedBuilder 避免手动 setState + 重建整个 Widget 树

void main() => runApp(const MaterialApp(home: _AnimDemo()));

class _AnimDemo extends StatefulWidget {
  const _AnimDemo();
  @override
  State<_AnimDemo> createState() => _AnimDemoState();
}

class _AnimDemoState extends State<_AnimDemo>
    with SingleTickerProviderStateMixin {
  late final AnimationController _ctrl;
  late final Animation<double> _scale;
  late final Animation<Color?> _color;

  @override
  void initState() {
    super.initState();
    _ctrl = AnimationController(
      vsync: this,
      duration: const Duration(milliseconds: 800),
    )..repeat(reverse: true); // 循环播放

    _scale = Tween<double>(begin: 1.0, end: 1.4).animate(
      CurvedAnimation(parent: _ctrl, curve: Curves.easeInOut),
    );
    _color = ColorTween(begin: Colors.blue, end: Colors.purple).animate(_ctrl);
  }

  @override
  void dispose() {
    _ctrl.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('动画演示')),
      body: Center(
        // AnimatedBuilder：只重建子树中真正依赖动画值的部分
        child: AnimatedBuilder(
          animation: _ctrl,
          builder: (_, child) {
            return Transform.scale(
              scale: _scale.value,
              child: Container(
                width: 120,
                height: 120,
                decoration: BoxDecoration(
                  color: _color.value,
                  borderRadius: BorderRadius.circular(16),
                ),
                child: child,
              ),
            );
          },
          child: const Icon(Icons.favorite, size: 48, color: Colors.white),
        ),
      ),
    );
  }
}

AnimatedBuilder：只重建必要部分 ​

dart
AnimatedBuilder(
  animation: controller,                    // 监听这个动画
  builder: (context, child) {              // 每次 tick 都调用 builder
    return Transform.scale(scale: scale.value, child: child);
  },
  child: const Icon(Icons.favorite),        // ← 这个子 Widget 只创建一次！
)

child 参数传进去的 Widget 只会创建一次，之后每帧只重建 builder 返回的结构。这比在 build 里直接用 _scale.value 然后 setState 重建整个 Widget 树高效得多。

常用过渡：隐式 vs 显式 ​

隐式动画（推荐首选） ​

给 Container 加 duration 和 curve，Flutter 自动处理动画——无需手写 AnimationController：

dart
AnimatedContainer(
  duration: const Duration(milliseconds: 300),
  curve: Curves.easeInOut,
  width: _expanded ? 200 : 100,
  height: _expanded ? 200 : 100,
  color: _expanded ? Colors.blue : Colors.red,
)

常用隐式组件：AnimatedContainer / AnimatedPadding / AnimatedPositioned / AnimatedOpacity / AnimatedScale / AnimatedCrossFade。

显式动画：需要精细控制时 ​

当你需要同时控制多个属性、自定义曲线、交错、延迟、组合时，AnimationController + Tween 是唯一选择。

交错动画（Staggered Animation） ​

在同一个 AnimationController 上挂多个 Tween，每个在不同时间段激活：

dart
// 0%~60% 缩放，60%~100% 淡入
final scale = Tween<double>(begin: 0, end: 1).animate(
  CurvedAnimation(parent: controller, curve: const Interval(0, 0.6)),
);
final fade = Tween<double>(begin: 0, end: 1).animate(
  CurvedAnimation(parent: controller, curve: const Interval(0.6, 1)),
);

常见坑 ​

高频踩坑点

  1. 忘记在 dispose 里释放 AnimationController：直接内存泄漏，Flutter 控制台会报警。
  2. AnimatedBuilder 的 child 用错：child 参数传进去 Widget 时如果是动态的（含变量），则仍然每帧重建——child 必须是固定不变的 Widget 实例。
  3. 一次动画挂太多监听：controller.addListener(listener) 多次后忘记 remove。优先用 .animate().animate() 链式 + AnimatedBuilder。
  4. 动画时长太长：移动端用户对动画的耐心是 200-400ms。>500ms 的动画大部分场景会嫌慢。
  5. 多个 TickerProvider 忘记改成多提供者：多个 AnimationController 时，State 需要 with TickerProviderStateMixin（复数 s）。

课后练习 ​

  1. 隐式 vs 显式：分别用 AnimatedContainer 和 AnimatedBuilder + AnimationController 做一个点击后变大变蓝的方块，对比两种写法的代码量和控制能力。
  2. 交错动画列表：一个 ListView 里 5 个卡片，点击按钮后从上到下依次淡入滑入，每个卡片错开 100ms。
  3. AnimatedSwitcher：用 AnimatedSwitcher 实现数字点击切换时的「向下滑出、向上滑入」效果（需要给数字加 Key）。
  4. 性能诊断：把你写的复杂动画在 DevTools Performance 面板跑一帧，看 build / layout / paint 各耗时多少，判断是否用 AnimatedBuilder 优化了。
