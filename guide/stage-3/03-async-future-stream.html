Future 与 Stream 异步 ​

学习目标 ​

学完本章，你将能够：

  • 理解 Future（单次）与 Stream（多次）的本质差异
  • 正确使用 async/await/async*/yield
  • 处理 Stream 的取消（内存泄漏高发点）
  • 掌握并发控制：Future.wait、sequential、取消、超时
  • 在 Widget 里用 FutureBuilder / StreamBuilder 响应异步变化

一句话区分

Future = 一个「未来才会有值的盒子」，只会成功或失败一次。Stream = 一条「持续流」，可以产出多个值、多次失败、完成或永远不结束。

Future：单次异步 ​

dart
// 声明异步函数
Future<String> fetchUser() async {
  await Future.delayed(const Duration(seconds: 1));
  return '张三';
}

// 调用
main() async {
  final name = await fetchUser();           // 同步写法读异步值
  print('你好, $name');
  // 或用 .then 链式
  fetchUser().then((n) => print('你好, $n'));
}

Future 有三种终态：value（成功）/ error（失败）/ never（永远不完成）。try-catch 捕获 error；.catchError 链式处理 error。

并发：Future.wait / Future.any ​

dart
// 并行等待所有，全部成功才继续（失败一个整体抛错）
final results = await Future.wait([
  fetchUser(),
  fetchPosts(),
  fetchSettings(),
]);

// 只要有一个完成就继续
final first = await Future.any([requestA, requestB]);

并发坑

await a; await b; 是串行执行。需要并行就用 Future.wait([a, b])。三个无依赖的网络请求串行比并行慢 2 倍。

超时与取消 ​

dart
// 超时
try {
  await fetchData().timeout(const Duration(seconds: 10));
} on TimeoutException {
  print('请求超时');
}

// 取消：Future 本身不可取消，需要外部 CancelToken（dio 有原生支持）
// 手动实现：
bool _cancelled = false;
Future<void> work() async {
  for (var i = 0; i < 10 && !_cancelled; i++) {
    await Future.delayed(const Duration(milliseconds: 200));
    print('step $i');
  }
}

Stream：持续事件 ​

运行示例
DartPad 运行环境将在滚动到此处时加载…

「运行 Future」按钮演示单次 await，「启动 Stream」按钮演示持续 5→4→3→2→1→0 事件流，每个事件以 Chip 展示。

查看完整源码
dart
import 'dart:async';
import 'package:flutter/material.dart';

// Future 与 Stream 实战
// Future = 单次异步结果，Stream = 连续事件流（可多次 emit）

void main() => runApp(const MaterialApp(home: _Demo()));

class _Demo extends StatefulWidget {
  const _Demo();
  @override
  State<_Demo> createState() => _DemoState();
}

class _DemoState extends State<_Demo> {
  String _futureResult = '等待中...';
  final List<int> _streamEvents = [];
  StreamSubscription<int>? _sub;
  bool _streamActive = false;

  @override
  void dispose() {
    _sub?.cancel(); // 必须取消，否则内存泄漏
    super.dispose();
  }

  // Future：一次返回
  Future<String> _loadAsync() async {
    await Future.delayed(const Duration(seconds: 1));
    return '✅ 数据加载完成：${DateTime.now().second}s';
  }

  // Stream：持续产出
  Stream<int> _countdown() async* {
    for (var i = 5; i >= 0; i--) {
      yield i;
      await Future.delayed(const Duration(milliseconds: 400));
    }
  }

  void _runFuture() async {
    setState(() => _futureResult = '加载中...');
    final r = await _loadAsync();
    setState(() => _futureResult = r);
  }

  void _toggleStream() {
    if (_streamActive) {
      _sub?.cancel();
      setState(() {
        _streamActive = false;
        _streamEvents.clear();
      });
    } else {
      setState(() {
        _streamActive = true;
        _streamEvents.clear();
      });
      _sub = _countdown().listen((event) {
        setState(() => _streamEvents.add(event));
      }, onDone: () {
        setState(() => _streamActive = false);
      });
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Future & Stream')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.stretch,
          children: [
            ElevatedButton(onPressed: _runFuture, child: const Text('运行 Future')),
            const SizedBox(height: 8),
            Text(_futureResult, style: const TextStyle(fontSize: 16)),
            const SizedBox(height: 24),
            ElevatedButton(
              onPressed: _toggleStream,
              child: Text(_streamActive ? '⏹ 停止 Stream' : '▶ 启动 Stream'),
            ),
            const SizedBox(height: 12),
            Wrap(
              spacing: 8,
              children: _streamEvents
                  .map((e) => Chip(label: Text('$e')))
                  .toList(),
            ),
          ],
        ),
      ),
    );
  }
}

创建 Stream ​

dart
// 方式一：async* + yield（最推荐）
Stream<int> countDown({required int from}) async* {
  for (var i = from; i >= 0; i--) {
    yield i;
    await Future.delayed(const Duration(milliseconds: 500));
  }
}

// 方式二：StreamController（需要手动 close）
final controller = StreamController<int>();
controller.sink.add(1);
controller.sink.addError('出错了');
controller.close(); // 必须 close，否则内存泄漏

订阅 Stream（三种） ​

dart
// 方式一：await for（异步循环，最简洁）
await for (final event in myStream) {
  print(event);
}

// 方式二：listen（返回 StreamSubscription，可取消）
final sub = myStream.listen(
  (event) => print(event),
  onError: (err) => print('错误: $err'),
  onDone: () => print('结束'),
);
sub.cancel(); // ← 重要！不 cancel 就内存泄漏

// 方式三：first / last / single 取一个值
final firstItem = await myStream.first;

Stream 的广播模式 ​

dart
// 默认 Stream 是 single-subscription（只能听一次）
// 广播流：可以多个监听者同时听
final controller = StreamController.broadcast();

选择 Stream 还是 Future

  • 网络请求（一次一个响应）→ Future
  • 用户输入流（每次敲一个字符）→ Stream
  • WebSocket（持续消息）→ Stream
  • 文件读取（逐行）→ Stream
  • 计时器 → Stream.periodic
  • 「我只关心最终结果」→ Future；「我关心中间过程」→ Stream

FutureBuilder / StreamBuilder：Widget 里消费异步 ​

dart
FutureBuilder<String>(
  future: fetchName(),                // ⚠ 不要在 build 里创建！
  builder: (context, snapshot) {
    if (snapshot.connectionState == ConnectionState.waiting) {
      return const CircularProgressIndicator();
    }
    if (snapshot.hasError) return Text('❌ ${snapshot.error}');
    return Text('你好, ${snapshot.data}');
  },
)

FutureBuilder 高频坑

不要在 build 方法里写 future: fetchData()——build 每帧都调，Future 就每帧重建，网络请求无限循环。正确做法：在 State 的 initState 里创建 Future 并存在 late final 变量里，build 里直接引用。

StreamBuilder 同理，builder 根据 snapshot 的状态（waiting / active / done / none）决定展示什么。

常见坑 ​

高频踩坑点

  1. StreamSubscription 忘记 cancel：监听 Stream 但用户离开页面后流还在飞，内存泄漏 + setState after dispose。State 的 dispose 里必须 sub.cancel()。
  2. Future 被忽略：unawaited(future) 明确表示故意不管；不加 unawaited 也不 await，Dart linter 会警告。
  3. StreamController 忘记 close：broadcast controller 尤其容易忘记，会导致监听者无法收到 done 事件。
  4. async 函数里 try-catch 不完整：catch 块要 rethrow 或正确处理，否则错误被静默吞掉。
  5. FutureBuilder 的 future 在 build 里重建：如上所述，要在 initState 里创建。

课后练习 ​

  1. 串行 vs 并行：用三个 1 秒延迟的 Future，分别用 await a; await b; await c（串行）和 await Future.wait([a, b, c])（并行），打印开始/结束时间戳，对比耗时。
  2. 倒计时 Stream：写一个 Stream<int> tick({required int seconds})，每秒 emit 一个剩余秒数，到 0 结束。用 StreamBuilder 做一个倒计时页面，有暂停/恢复按钮（用 BehaviorSubject 或外部 state 控制）。
  3. 错误与重试：给一个 Stream 加 handleError + expand 实现失败自动重试 3 次，仍失败则 emit 一个错误状态。
  4. 组合两个 Stream：用 StreamGroup.merge([s1, s2])（rxdart）或手动合并，把两个独立的 Stream 合并成一个时间戳交替的 Stream。
