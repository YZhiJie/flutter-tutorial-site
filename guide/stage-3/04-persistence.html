本地持久化 ​

学习目标 ​

学完本章，你将能够：

  • 区分三类持久化场景：键值对（简单）/ 结构化（SQLite）/ 文件（媒体/文档）
  • 使用 shared_preferences 做简单偏好存储
  • 使用 sqflite 做 SQLite 结构化存储
  • 使用 Hive / Isar 做高性能 NoSQL 存储
  • 理解持久化与网络层的配合策略（缓存优先 / 网络回源）

选型决策树

  • ✅ 简单键值（用户偏好、token、简单设置）→ shared_preferences
  • ✅ 结构化数据（多表、关联查询、复杂筛选）→ sqflite
  • ✅ 高性能读写、无需 SQL 查询、跨平台 → Hive / Isar
  • ✅ 大文件（图片、视频、下载）→ path_provider + dart:io File
  • ❌ 不要用 shared_preferences 存列表，不要用 sqflite 存单条配置

shared_preferences：最简单 ​

dart
// pubspec.yaml: shared_preferences: ^2.2.0
import 'package:shared_preferences/shared_preferences.dart';

// 写入
final prefs = await SharedPreferences.getInstance();
await prefs.setString('username', 'zhangsan');
await prefs.setBool('dark_mode', true);
await prefs.setInt('score', 100);

// 读取（都是 nullable，加 ?? 给默认值）
final name = prefs.getString('username') ?? '';
final dark = prefs.getBool('dark_mode') ?? false;
final score = prefs.getInt('score') ?? 0;

// 删除
await prefs.remove('username');
await prefs.clear();

注意：SharedPreferences.getInstance() 是异步的，但只在第一次调用时慢。之后调用返回同一个实例。把它存起来别每次都 await。

sqflite：结构化数据 ​

dart
// pubspec.yaml: sqflite: ^2.3.0  path_provider: ^2.1.0
import 'package:sqflite/sqflite.dart';
import 'package:path_provider/path_provider.dart';

// 初始化：打开或创建数据库
final db = openDatabase(
  'todo.db',
  version: 1,
  onCreate: (db, v) async {
    await db.execute('''
      CREATE TABLE todos (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        title TEXT NOT NULL,
        done INTEGER NOT NULL DEFAULT 0,
        created_at TEXT NOT NULL
      )
    ''');
  },
);

// 增
await db.insert('todos', {'title': '买牛奶', 'done': 0, 'created_at': DateTime.now().toIso8601String()});

// 查
final List<Map<String, dynamic>> rows = await db.query(
  'todos',
  where: 'done = ?',
  whereArgs: [0],
  orderBy: 'created_at DESC',
);

// 改
await db.update('todos', {'done': 1}, where: 'id = ?', whereArgs: [42]);

// 删
await db.delete('todos', where: 'id = ?', whereArgs: [42]);

sqflite 的所有 API 都是异步的——每个 insert/query 都要 await。在 UI 层用 FutureBuilder 包裹，或用状态管理框架做 Repository 模式封装。

迁移与版本升级 ​

openDatabase 的 onUpgrade 回调处理 schema 变化：

dart
version: 2,
onUpgrade: (db, oldV, newV) async {
  if (oldV < 2) {
    await db.execute('ALTER TABLE todos ADD COLUMN priority INTEGER DEFAULT 0');
  }
},

Hive / Isar：高性能 NoSQL ​

不想写 SQL 又想要结构化存储，Hive 和 Isar 是更好的选择。

Hive（2.x） ​

dart
// 1. 注册适配器并初始化
Hive.registerAdapter(TodoAdapter());
await Hive.initFlutter();

// 2. 打开盒子
final box = await Hive.openBox<Todo>('todos');

// 3. 简单 CRUD（完全同步！）
box.put('key1', Todo(title: '买牛奶', done: false));
final todo = box.get('key1');
box.delete('key1');

优势：纯 Dart、跨平台、支持 web、同步 API（无 async await）。

Isar（3.x） ​

dart
// Isar 支持查询、索引、多集合
@collection
class Todo {
  Id id = Isar.autoIncrement;
  late String title;
  bool done = false;
}

final todos = await isar.todos.filter().doneEqualTo(false).findAll();

优势：真正的 ORM、编译时代码生成、强类型查询 API（比 SQL 安全）、性能接近 sqflite。

大文件：path_provider + dart:io ​

图片、视频、下载文档等大文件存应用文档目录：

dart
import 'package:path_provider/path_provider.dart';
import 'dart:io';

final dir = await getApplicationDocumentsDirectory();
final file = File('${dir.path}/cache/image_123.jpg');
await file.writeAsBytes(imageBytes);
final bytes = await file.readAsBytes();

常用目录：

  • getApplicationDocumentsDirectory() — 应用专属，系统不清理
  • getTemporaryDirectory() — 系统可能自动清理的缓存目录
  • getApplicationSupportDirectory() — 跨平台统一存放应用数据
  • 不要用 Directory.current（可能是不期望的路径）

常见坑 ​

高频踩坑点

  1. shared_preferences 存 list：不支持原生 List API，要 JSON 序列化后存 String。简单场景可以接受，复杂场景别折腾。
  2. sqflite 查询后手动 toList()：db.query 返回的 List 不可变。直接修改会报 UnsupportedError。创建副本：List<Map<String, dynamic>> rows = (await db.query('todos')).toList();
  3. 忘记 dispose：Hive 要在应用退出时 Hive.close()。sqflite 的数据库实例建议全局单例不要频繁 open/close。
  4. 写入主线程阻塞：大文件或大量数据写入 SQLite 会阻塞 UI。把重操作放到 Isolate 或用 compute() 跑。
  5. 路径硬编码：永远不要手动拼路径，用 path 包的 join(dir.path, 'subfolder', 'file.txt')。

课后练习 ​

  1. 偏好持久化：做一个主题切换开关（亮/暗），切换后用 shared_preferences 持久化，重启 App 后记得用户的选择。
  2. 本地 Todo 应用：用 sqflite 或 Hive 实现完整 Todo：增删改查、标记完成、按优先级排序。做 Repository 层封装（数据来源唯一）。
  3. 缓存策略：网络请求 → 成功时存本地 → 下次启动优先展示本地数据同时后台刷新。用 DateTime.now().difference(lastFetch).inMinutes > 15 判断过期。
  4. 图片缓存：用 path_provider 的 temp 目录缓存网络图片，文件名用 URL 的 hash，做一个带过期清理的简单缓存层。
