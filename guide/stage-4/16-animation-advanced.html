动画进阶与物理动画 ​

学习目标 ​

学完本章，你将能够：

  • 区分隐式动画、显式动画、物理动画、自绘动画四层体系，并按场景选型
  • 掌握 AnimationController 与 Ticker 的生命周期，理解 vsync 和 TickerMode 的作用
  • 用 CurvedAnimation、TweenSequence 编排带缓动、停顿、分段的复杂动画
  • 用 SpringSimulation 或手写弹簧方程实现能承接手势速度的物理动画
  • 解释 ScrollPhysics、PageView 的滚动动量与分页吸附原理
  • 用 AnimatedBuilder、RepaintBoundary、repaint 把每帧开销压到最小

先选层，再写代码

能用隐式动画（AnimatedContainer 等）就不要上 AnimationController；需要和手势速度衔接时才用物理动画；只有逐帧绘制（粒子、波纹）才自己接 Ticker。

一、四层动画体系 ​

层级代表 API适合控制粒度
隐式动画AnimatedContainer、AnimatedOpacity属性值变化后的过渡低，只改目标值
显式动画AnimationController + Tween多属性编排、可暂停/反向高
物理动画SpringSimulation、ScrollPhysics手势松手后的惯性、回弹由物理参数决定
自绘动画AnimationController + CustomPainter粒子、波纹、图表最高，逐帧控制

隐式动画内部同样会创建 AnimationController，只是帮你隐藏了样板代码；当动画需要「中途反向」「跟随手指」「松手后按速度继续」时，隐式动画就力不从心了。

二、AnimationController 与 Ticker 的生命周期 ​

dart
class _BoxState extends State<Box> with SingleTickerProviderStateMixin {
  late final AnimationController _c = AnimationController(
    vsync: this,                                  // 用 Ticker 驱动
    duration: const Duration(milliseconds: 400),
    reverseDuration: const Duration(milliseconds: 250),
  );

  @override
  void dispose() {
    _c.dispose();                                 // 必须释放 Ticker
    super.dispose();
  }
}
  • vsync 接收一个 TickerProvider，它把动画回调挂到 SchedulerBinding 的帧回调上；Ticker 只在有帧时推进，不会用 Timer。
  • 一个页面有多个控制器时用 TickerProviderStateMixin，只有一个时用 SingleTickerProviderStateMixin 更省。
  • 控制器应在 initState 创建、在 dispose 释放；绝不能在 build 里 new，否则每帧都会泄漏一个 Ticker。
  • 路由被其他页面完全覆盖时，TickerMode 会自动置为 false，Ticker 被 mute，动画暂停且不再请求帧——这是免费的省电优化。

TickerMode 也会「吃掉」你的自定义动画

如果你用 Ticker 或 AnimationController 做倒计时、游戏循环，页面切到后台时它们会被自动暂停。需要继续运行就得显式 TickerMode(enabled: true)，但更推荐在生命周期回调里暂停业务，而不是和框架对着干。

三、编排：CurvedAnimation 与 TweenSequence ​

dart
final curved = CurvedAnimation(
  parent: _c,
  curve: Curves.easeOutCubic,
  reverseCurve: Curves.easeInCubic,
);

final sequence = TweenSequence<double>([
  TweenSequenceItem(
    tween: Tween(begin: 0, end: 1)
        .chain(CurveTween(curve: Curves.easeOut)),
    weight: 40,
  ),
  TweenSequenceItem(tween: ConstantTween<double>(1), weight: 20),
  TweenSequenceItem(
    tween: Tween(begin: 1, end: 0)
        .chain(CurveTween(curve: Curves.easeIn)),
    weight: 40,
  ),
]).animate(_c);
  • TweenSequence 的 weight 是相对权重，框架会归一化；上例前 40%、中间停 20%、后 40%。
  • 想做「错峰入场」，用 Interval(0.2, 0.6, curve: Curves.easeOut) 给不同子动画切时间段。
  • CurvedAnimation 从 Flutter 3.13 起也需要 dispose()，忘记释放会在 debug 下报泄漏断言。

组合优于堆叠

Tween.chain(CurveTween(...)) 可以把「数值变化」和「缓动」组合成一个 Animatable，比在回调里手算 curve.transform(t) 更清晰，也更容易复用。

四、弹簧物理：SpringSimulation 与手写方程 ​

弹簧的运动方程是：

text
m * x'' = -k * (x - target) - c * x'

其中 k 是刚度、c 是阻尼系数、m 是质量。用阻尼比 ζ = c / (2 * sqrt(k * m)) 描述手感：

阻尼比行为常见用途
ζ < 1欠阻尼，越过目标后来回振荡活泼的回弹、开关
ζ = 1临界阻尼，最快且不振荡面板展开
ζ > 1过阻尼，慢慢靠近稳重、大对象

Flutter 内置了 SpringSimulation（来自 package:flutter/physics.dart，不是第三方包）：

dart
final spring = SpringDescription.withDampingRatio(
  mass: 1,
  stiffness: 180,
  ratio: 0.45, // ζ
);

final controller = AnimationController.unbounded(vsync: this);
controller.animateWith(
  SpringSimulation(spring, controller.value, 1.0, velocity),
);

velocity 可以来自 DragEndDetails.primaryVelocity，这样松手瞬间速度无缝衔接。也可以直接用 AnimationController.animateWith 的返回值监听 status。

有界控制器会把回弹「削平」

默认 AnimationController 的取值被限制在 0~1，弹簧越过目标的那一段会被 clamp，看起来像卡住。物理动画请用 AnimationController.unbounded，再在需要时把值映射到 UI 范围。

不引入任何包也能手写，核心就是几行积分（演示 App 用的就是这套）：

dart
final c = zeta * 2 * math.sqrt(k * m);
for (var i = 0; i < 4; i++) {       // 子步，防止大步长发散
  final h = dt / 4;
  final a = (-k * (x - target) - c * v) / m;
  v += a * h;
  x += v * h;
}

五、滚动与 PageView 的物理 ​

  • ScrollPhysics.createBallisticSimulation(position, velocity) 返回一个 Simulation?；返回 null 表示「到这里就停」。
  • ScrollPosition 用 BallisticScrollActivity 驱动这个 simulation，内部同样是 AnimationController.unbounded + animateWith。
  • 这些滚动模拟都实现 Simulation，只暴露 x(t)、dx(t)、isDone(t)，滚动位置按它逐帧求值。
  • Android 风格用 ClampingScrollSimulation(position: ..., velocity: ..., friction: 0.015)：按摩擦衰减，末端夹紧。
  • iOS 风格用 BouncingScrollSimulation(position: ..., velocity: ..., leadingExtent: ..., trailingExtent: ..., spring: ...)：越界后按弹簧回弹。
  • PageView 的 PageScrollPhysics 会把当前位置四舍五入到最近的页（阈值约半页），再用 ScrollSpringSimulation 收尾；所以轻扫也能整页切换。

想自定义「滚动停止时吸附到 200px 网格」，重写 createBallisticSimulation 并返回：

dart
final target = (position.pixels / 200).round() * 200.0;
return ScrollSpringSimulation(
  SpringDescription.withDampingRatio(mass: 1, stiffness: 100, ratio: 0.9),
  position.pixels,
  target,
  velocity,
);

六、性能：局部重建、TickerMode 与 RepaintBoundary ​

  • AnimatedBuilder 只重建 builder 返回的子树；把不变化的子组件通过 child 参数传入，可避免重复构建。
  • 纯绘制动画可以让 CustomPainter 直接监听动画：CustomPaint(painter: XPainter(repaint: _c))，Widget 树完全不重建，只触发重绘。
  • 给动画区域包 RepaintBoundary，把重绘隔离在一个图层里，避免整页重绘；但不要给每个小格子都包，图层太多反而更慢。
  • 列表滚动时给 item 加 RepaintBoundary 通常有效；如果 item 内部还有动画，图层会被反复标记，需要实测。
  • TickerMode 已自动处理路由遮挡；列表离屏项可用 TickerMode(enabled: false) 或让动画跟随可见性。

flutter_animate 这类库把「链式声明动画」做成扩展方法（.animate().fadeIn().slideX()），适合快速堆叠入场效果；它会额外引入依赖和一层封装，核心机制仍是 AnimationController，不存在性能魔法。

dart
import 'dart:math' as math;
import 'package:flutter/material.dart';
import 'package:flutter/scheduler.dart';

// 手写弹簧：a = (-k * (x - target) - c * v) / m
// 用半隐式欧拉积分；真实项目也可用 SpringSimulation + animateWith()。

void main() => runApp(const _SpringDemo());

class _SpringDemo extends StatefulWidget {
  const _SpringDemo();
  @override
  State<_SpringDemo> createState() => _SpringDemoState();
}

class _SpringDemoState extends State<_SpringDemo>
    with SingleTickerProviderStateMixin {
  late final Ticker _ticker;
  final Stopwatch _watch = Stopwatch();
  int _lastUs = 0;
  double _x = 0.1; // 位置 0~1
  double _v = 0; // 速度
  double _target = 0.9;
  // k 刚度、m 质量、c 阻尼系数：ζ = c / (2 * sqrt(k * m))
  static const double _k = 140;
  static const double _m = 1;
  static const double _c = 10;
  @override
  void initState() {
    super.initState();
    _watch.start();
    _ticker = createTicker(_onTick)..start();
  }
  void _onTick(Duration _) {
    final now = _watch.elapsedMicroseconds;
    final dt = ((now - _lastUs) / 1e6).clamp(0.0, 0.05).toDouble();
    _lastUs = now;
    for (var i = 0; i < 4; i++) {
      final h = dt / 4; // 4 次子步，防止大步长发散
      final a = (-_k * (_x - _target) - _c * _v) / _m;
      _v += a * h;
      _x += _v * h;
    }
    setState(() {});
  }
  @override
  void dispose() {
    _ticker.dispose();
    _watch.stop();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    final zeta = _c / (2 * math.sqrt(_k * _m));
    return MaterialApp(
      home: Scaffold(
        appBar: AppBar(title: const Text('手写弹簧动画')),
        body: Padding(
          padding: const EdgeInsets.all(24),
          child: Column(children: [
            Text('ζ = ${zeta.toStringAsFixed(2)}   '
                'x = ${_x.toStringAsFixed(3)}   v = ${_v.toStringAsFixed(3)}'),
            const SizedBox(height: 24),
            Expanded(
              child: GestureDetector(
                onTap: () => setState(
                  () => _target = _target > 0.5 ? 0.1 : 0.9,
                ),
                child: CustomPaint(
                  painter: _SpringPainter(x: _x, target: _target),
                  child: const SizedBox.expand(),
                ),
              ),
            ),
            const Text('点击画面切换目标，观察回弹与稳定过程'),
          ]),
        ),
      ),
    );
  }
}

class _SpringPainter extends CustomPainter {
  _SpringPainter({required this.x, required this.target});
  final double x;
  final double target;

  @override
  void paint(Canvas canvas, Size size) {
    final y = size.height / 2;
    final left = 24.0;
    final right = size.width - 24;
    final targetX = left + (right - left) * target;
    final ballX = left + (right - left) * x.clamp(0.0, 1.0).toDouble();
    canvas.drawLine(
      Offset(left, y), Offset(right, y), Paint()..color = Colors.grey.shade400);
    canvas.drawLine(
      Offset(targetX, y - 30), Offset(targetX, y + 30),
      Paint()..color = Colors.orange..strokeWidth = 2);
    canvas.drawCircle(Offset(ballX, y), 20, Paint()..color = Colors.blueAccent);
    canvas.drawCircle(
      Offset(ballX, y), 20,
      Paint()..style = PaintingStyle.stroke..color = Colors.white..strokeWidth = 2);
  }

  @override
  bool shouldRepaint(covariant _SpringPainter old) =>
      old.x != x || old.target != target;
}

常见坑 ​

高频踩坑点

  1. 控制器不 dispose：AnimationController 持有 Ticker，页面销毁后仍在请求帧，DevTools 会报泄漏；CurvedAnimation 同理。
  2. 在 build 里创建控制器：每次重建都新建一个，旧的不释放，内存和帧回调一起涨。
  3. 弹簧用有界控制器：回弹被 clamp 截断成「卡住」，误以为是物理参数不对。
  4. AnimatedBuilder 包住整页：动画每帧重建整棵树；把 builder 缩到真正变化的那一小块，静态部分用 child。
  5. 忘记处理手势速度：松手时直接把 velocity 丢掉，动画会从 0 速开始，手感「断档」。
  6. 用 setState 驱动 60fps 自绘：整棵子树每帧重建；改用 CustomPainter(repaint: animation) 或 AnimatedBuilder。

课后练习 ​

  1. 手感对比：用同一个弹簧，分别取 ζ = 0.3 / 1.0 / 1.5，录屏对比「回弹次数」和「稳定时间」，写下你的选择依据。
  2. 速度衔接：给一个方块加拖拽，松手时把 DragEndDetails.primaryVelocity 传给 SpringSimulation，对比「有速度」与「速度为 0」的差别。
  3. TweenSequence 编排：做一段「放大 → 停 200ms → 缩小」的入场动画，要求总时长 800ms，并让三段权重可配置。
  4. 自定义吸附：写一个 ScrollPhysics 子类，让列表停止时吸附到 160px 的整数倍，验证快速轻扫也能吸附。
  5. 性能测量：用 DevTools Performance 对比「整页 setState」与「CustomPainter(repaint:)」两种实现的 raster 时间与 rebuild 次数。
