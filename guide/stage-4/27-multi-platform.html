多端延伸：桌面与 Web ​

学习目标 ​

学完本章，你将能够：

  • 说清 macOS / Windows / Linux 与 Web 的支持现状、插件缺口与「移动端思维」陷阱
  • 用窗口管理、平台菜单、托盘与快捷键把移动 App 变成可用的桌面 App
  • 处理桌面文件系统、macOS 沙盒 entitlement，以及签名 / 公证 / 商店分发
  • 理解 CanvasKit 与 skwasm 的差异，控制 Web 首屏体积与构建参数
  • 规避 Web 的 IO、插件、后台限制，并正确配置 history 路由与 SEO 策略
  • 用 capabilities 探测 + 断点做自适应

不是「多一个构建目标」

桌面与 Web 不是把 APK 换个壳：输入设备、窗口生命周期、文件权限、包分发、性能预算都变了。真正要做的是同一套业务内核 + 按能力分层的 UI。

一、桌面：能力现状与心智差异 ​

平台支持状态常见缺口
macOS稳定，官方重点支持沙盒默认开启、公证流程、部分移动插件无实现
Windows稳定安装包需自行签名、部分插件依赖 WinRT
Linux稳定发行版差异大、打包格式自选、Firebase 等生态弱
Web稳定但受限无原生插件、无文件系统、首屏体积与 SEO 是硬约束
bash
flutter create --platforms=macos,windows,linux .
flutter build macos && flutter build windows --release && flutter build linux --release

桌面目录会多出 macos/Runner/、windows/runner/、linux/、web/。最容易被忽略的两件事：

  • 没有「返回键」：页面栈退出要靠菜单、快捷键或显式按钮。
  • 鼠标与键盘是主角：hover、右键菜单、Tab 焦点、快捷键都要补。

二、窗口、菜单与托盘 ​

窗口尺寸与位置用 window_manager 管理：

dart
WidgetsFlutterBinding.ensureInitialized();
await windowManager.ensureInitialized();
await windowManager.waitUntilReadyToShow(
  const WindowOptions(size: Size(1100, 760), minimumSize: Size(720, 520), center: true),
  () async { await windowManager.show(); await windowManager.focus(); },
);
能力推荐做法注意
窗口控制window_manager初始化必须在 runApp 前完成
菜单栏macOS 用 PlatformMenuBar；其他平台自定义快捷键按平台习惯（⌘ / Ctrl）
托盘tray_managermacOS 用 template 图标，Windows 用 .ico
快捷键Shortcuts + Actions先判断焦点，避免输入框误触
拖拽文件desktop_drop拖入后校验扩展名与大小

菜单与快捷键是平台约定

macOS 的「退出」在应用菜单、Windows 在「文件」菜单；⌘Q 与 Alt+F4 不能互换。按平台习惯分支，比强行统一体验更专业。

三、文件系统、沙盒、签名与公证 ​

  • 用户选择的文件用 file_picker，应用目录用 path_provider。
  • macOS 默认开启 App Sandbox，读写用户选择的文件需 com.apple.security.files.user-selected.read-write。
  • Windows 没有沙盒，但 UAC、杀毒误报、中文路径都要测。
  • Linux 依赖 XDG 目录规范与 portal，别硬编码 ~/.config。

macOS 分发链路：

bash
codesign --deep --force --options runtime --sign "Developer ID Application: ..." MyApp.app
xcrun notarytool submit MyApp.zip --keychain-profile "notary" --wait
xcrun stapler staple MyApp.app
spctl --assess --type execute --verbose MyApp.app

Windows 用 signtool；Linux 常见 deb、AppImage、snap、flatpak。三端都没有统一点击安装的答案，发布前先把安装器、自动更新、崩溃收集想清楚。

不要假设桌面文件路径

/Users/...、C:\...、/home/... 三套规则，沙盒、只读目录、网络盘都会让 File.exists() 返回意外结果。统一走 path_provider 与用户选择。

四、Web：CanvasKit、skwasm 与构建 ​

CanvasKitskwasm
技术Skia 编译为 WebAssemblySkia + WasmGC，多线程渲染
包体首次需下载 CanvasKit wasm依赖浏览器 WasmGC 支持
兼容性主流浏览器均可较新 Chrome / Firefox / Safari
开启方式默认flutter build web --wasm

HTML renderer 已在 Flutter 3.29 移除，别再找 --web-renderer html。

bash
flutter build web --release
flutter build web --release --wasm
flutter build web --release --base-href /app/

首屏体积主要来自 CanvasKit / skwasm 运行时、字体、图片、未裁剪图标。可用手段：图标 tree-shake-icons、大图按显示尺寸预压缩、非首屏路由 deferred import、--pwa-strategy 控制缓存、中文字体做字符子集。

Web 首屏不是「越小越好」

CanvasKit 是渲染引擎，砍掉就画不出来。目标是先出可交互骨架，再加载重资源：HTML/CSS 占位、延迟路由、图片懒加载，比单纯压包更有效。

五、Web 的限制、history 路由与 SEO ​

  • 不能用 dart:io、path_provider 与大部分原生插件；文件只能走浏览器 File API / IndexedDB。
  • 没有真正的后台任务，页面关闭即停止；后台标签页的定时器会被节流。
  • 受同源策略与 CORS 约束，接口必须放行 Web 域名。
  • 读不到 IMEI、通讯录等系统能力。

路由默认 hash 模式（/#/detail）。要 path 模式：

dart
import 'package:flutter_web_plugins/url_strategy.dart';

void main() {
  usePathUrlStrategy(); // 服务端需把所有路径回退到 index.html
  runApp(const MyApp());
}

服务端必须配 SPA fallback（Nginx try_files ... /index.html），否则刷新详情页 404。

SEO 是 Flutter Web 的结构性短板：文字画在 canvas 上，搜索引擎抓不到正文。

目标做法
营销落地页静态 HTML / SSG 单独做，再跳 Flutter 应用
内容型站点不要用 Flutter Web 承载正文
必须单页应用语义化 <title>、meta、sitemap，配合预渲染服务
分享卡片服务端按 URL 返回 OG 标签，而不是客户端注入

六、能力探测与断点自适应 ​

不要到处写 Platform.isAndroid，先抽象成能力集合：

dart
import 'package:flutter/foundation.dart';

Set<String> get capabilities => <String>{
      if (!kIsWeb) 'filesystem',
      if (!kIsWeb && (defaultTargetPlatform == TargetPlatform.macOS ||
          defaultTargetPlatform == TargetPlatform.windows)) 'window-controls',
      if (kIsWeb) 'service-worker',
    };

需要 dart:io 时用条件导入（io.dart / web.dart），别让 Web 编译碰到 Platform。

布局用 LayoutBuilder 的宽度断点，而不是平台判断：

dart
LayoutBuilder(
  builder: (context, constraints) {
    final compact = constraints.maxWidth < 600;
    final expanded = constraints.maxWidth >= 840;
    return Scaffold(
      body: Row(children: <Widget>[
        if (!compact) NavigationRail(selectedIndex: _index, onDestinationSelected: _select, destinations: _destinations),
        Expanded(child: _content(expanded)),
      ]),
      bottomNavigationBar: compact
          ? NavigationBar(selectedIndex: _index, onDestinationSelected: _select, destinations: _destinations)
          : null,
    );
  },
)

Material 3 常用断点：<600 紧凑、600~840 中等、>=840 展开。展开态做双栏（列表 + 详情），而不是把手机布局拉宽。MediaQuery.sizeOf(context) 只订阅尺寸，比 MediaQuery.of 少触发无关重建；但布局决策仍优先用 LayoutBuilder 的局部约束。

dart
import 'package:flutter/material.dart';

// 断点自适应：<600 底部导航，>=600 侧边栏；判断只看父容器宽度。
void main() => runApp(const MaterialApp(home: _AdaptivePage()));

class _AdaptivePage extends StatefulWidget {
  const _AdaptivePage();
  @override
  State<_AdaptivePage> createState() => _AdaptivePageState();
}

class _AdaptivePageState extends State<_AdaptivePage> {
  double _width = 390;
  int _index = 0;
  static const List<String> _tabs = <String>['首页', '搜索', '设置'];
  @override
  Widget build(BuildContext context) {
    final theme = Theme.of(context);
    final w = _width.round();
    return Scaffold(
      body: Column(
        children: <Widget>[
          Row(
            children: <Widget>[
              SizedBox(
                width: 150,
                child: Text('宽 $w · ${w < 600 ? 'Compact' : w < 840 ? 'Medium' : 'Expanded'}',
                    style: theme.textTheme.bodySmall),
              ),
              Expanded(
                child: Slider(
                  value: _width,
                  min: 320,
                  max: 1200,
                  onChanged: (v) => setState(() => _width = v),
                ),
              ),
            ],
          ),
          Expanded(
            child: Center(
              child: Container(
                width: _width,
                decoration: BoxDecoration(
                  border: Border.all(color: theme.colorScheme.outlineVariant),
                  borderRadius: BorderRadius.circular(12),
                ),
                child: LayoutBuilder(
                  builder: (context, c) {
                    final compact = c.maxWidth < 600;
                    final expanded = c.maxWidth >= 840;
                    return Column(
                      children: <Widget>[
                        Expanded(
                          child: Row(
                            children: <Widget>[
                              if (!compact)
                                NavigationRail(
                                  selectedIndex: _index,
                                  onDestinationSelected: (i) => setState(() => _index = i),
                                  destinations: <NavigationRailDestination>[
                                    for (var i = 0; i < _tabs.length; i++)
                                      NavigationRailDestination(
                                        icon: Icon(switch (i) {
                                          0 => Icons.home_outlined,
                                          1 => Icons.search,
                                          _ => Icons.settings_outlined,
                                        }),
                                        label: Text(_tabs[i]),
                                      ),
                                  ],
                                ),
                              Expanded(
                                child: Padding(
                                  padding: const EdgeInsets.all(12),
                                  child: Text('${_tabs[_index]}\n\n'
                                      '${expanded ? '>=840：这里可放双栏列表 + 详情。' : '单栏内容区，信息层级不变。'}'),
                                ),
                              ),
                            ],
                          ),
                        ),
                        if (compact)
                          NavigationBar(
                            selectedIndex: _index,
                            onDestinationSelected: (i) => setState(() => _index = i),
                            destinations: <NavigationDestination>[
                              for (var i = 0; i < _tabs.length; i++)
                                NavigationDestination(
                                  icon: Icon(switch (i) {
                                    0 => Icons.home_outlined,
                                    1 => Icons.search,
                                    _ => Icons.settings_outlined,
                                  }),
                                  label: _tabs[i],
                                ),
                            ],
                          ),
                      ],
                    );
                  },
                ),
              ),
            ),
          ),
        ],
      ),
    );
  }
}

常见坑 ​

高频踩坑点

  1. 用 Platform.isAndroid 判断 Web：dart:io 在 Web 不存在，直接编译失败。用 kIsWeb 与 defaultTargetPlatform。
  2. 桌面窗口不设最小尺寸：用户拖到 200px 宽，整页布局溢出。
  3. 把移动端手势当桌面交互：右键菜单、hover 反馈、Esc 关闭弹层不会自动出现。
  4. Web 刷新 404：用了 path 路由却没配 SPA fallback。
  5. Web 首屏塞满资源：CanvasKit、字体、大图、全部路由一次加载，白屏时间劝退。

课后练习 ​

  1. 窗口化：给现有 App 加 window_manager，设置最小尺寸、居中启动，并记住上次位置。
  2. 平台菜单：macOS 加「文件 / 编辑 / 帮助」菜单与 ⌘O，Windows 用 Ctrl 版本。
  3. 能力探测：实现 capabilities 集合，让「打开文件」按钮在 Web 自动禁用并提示原因。
  4. 断点改造：<600 底部栏、>=600 NavigationRail、>=840 双栏，补两个宽度的 widget test。
