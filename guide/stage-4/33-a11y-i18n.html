无障碍与国际化适配 ​

学习目标 ​

学完本章，你将能够：

  • 用 Semantics / ExcludeSemantics / MergeSemantics 构建可被屏幕阅读器理解的语义树
  • 控制 TalkBack / VoiceOver 的朗读顺序，并用 SemanticsService.announce 播报动态变化
  • 适配系统字号（textScaler），让布局在大字号下不溢出
  • 处理对比度、焦点顺序与键盘导航，满足 WCAG 基线
  • 用 intl + ARB + gen-l10n 完成复数、性别、日期与数字的本地化
  • 用 Directionality 与 EdgeInsetsDirectional 正确支持 RTL，并支持运行时切换语言

两个独立但常一起出现的话题

无障碍（a11y）解决「看得见、听得见、点得到」；国际化（i18n）解决「语言、方向、格式」。两者都要求不依赖固定尺寸与固定文案长度。

一、Semantics：给 UI 加一层可朗读描述 ​

Semantics 不会改变视觉，只向系统暴露一棵语义树，TalkBack / VoiceOver 读的就是这棵树。

属性作用
label朗读的主文本，如「余额 128.50 元」
hint操作提示，如「双击展开」
value当前值，如「已选中，第 2 项」
button / link / header角色标记，影响朗读语气与导航
sortKey同级节点的朗读顺序
onTap语义层的点击动作，供辅助技术触发
dart
Semantics(
  label: '余额 128.50 元',
  button: true,
  onTap: _openBalance,
  child: ExcludeSemantics(
    child: Row(children: [Icon(Icons.account_balance_wallet), Text('128.50')]),
  ),
)
  • ExcludeSemantics 把子树的语义整体移除，避免图标和数字被拆成两个节点重复朗读。
  • MergeSemantics 把子树合并成一个节点，适合「标题 + 副标题 + 开关」这种本来就该一起读的组合。
  • 装饰性图片用 ExcludeSemantics 或 Image(semanticLabel: '') 跳过。

不要用 Semantics 覆盖真实文本

Semantics(label: ...) 只应该补充信息，而不是替代可见文本。可见文本会自动进入语义树，再手动包一层容易产生重复朗读；先看默认语义，再决定是否合并或排除。

二、屏幕阅读器与遍历顺序 ​

  • TalkBack（Android）与 VoiceOver（iOS）默认按语义树的绘制顺序遍历，通常就是 Widget 树顺序。
  • 视觉顺序与代码顺序不一致时（如 Stack 里的浮层），用 OrdinalSortKey 显式排序：
dart
Semantics(
  sortKey: const OrdinalSortKey(1),
  child: const Text('第一步：选择城市'),
)
  • 动态内容（下单成功、验证码已发送）用 SemanticsService.announce('已发送验证码', TextDirection.ltr)，或给容器加 liveRegion: true 让系统主动播报。
  • 自定义手势（如滑动删除）要提供等价的可点击操作，否则辅助技术用户无法完成。

三、动态字号与布局自适应 ​

MediaQuery.textScalerOf(context) 返回系统的字号缩放；TextScaler.linear(1.3) 可用于局部预览或测试。

dart
final scaler = MediaQuery.textScalerOf(context);
// 只对某个子树限制上限，避免超大字号把布局撑爆
MediaQuery(
  data: MediaQuery.of(context).copyWith(
    textScaler: scaler.clamp(maxScaleFactor: 2.0),
  ),
  child: child,
)
常见写法大字号下的问题建议
SizedBox(height: 48, child: Text(...))文字被裁切用 ConstrainedBox + minHeight，或让父级自适应
单行 Row 放多个长文本溢出黄黑条Flexible + maxLines + TextOverflow.ellipsis
固定 fontSize: 12 的说明文字系统放大后仍很小用 Theme 的 bodySmall，跟随缩放

不要「锁死」字号缩放

用 MediaQuery(textScaler: TextScaler.noScaling) 把整个 App 锁死，是最常见的无障碍事故。只对确实无法自适应的局部（如图表刻度）做上限限制，上限也不应低于 1.3。

四、对比度、焦点与键盘导航 ​

  • WCAG AA：正文对比度 ≥ 4.5:1，大字号（≥ 18pt 或 14pt 粗体）≥ 3:1；不要只用颜色区分状态。
  • Flutter 的 ColorScheme 已提供成对的 onXxx 颜色，优先用主题色而不是手写十六进制。
  • 键盘/手柄导航：FocusTraversalGroup 包住一个区域，FocusTraversalOrder 指定组内顺序；桌面端与平板外接键盘都需要。
  • 焦点必须有可见指示：InkWell / Button 自带 focusColor，自定义 GestureDetector 则要用 FocusableActionDetector 补上。

五、国际化：intl + ARB + gen-l10n ​

bash
flutter pub add intl
flutter gen-l10n

l10n.yaml 里声明 arb-dir: lib/l10n、template-arb-file: app_en.arb，输出 app_localizations.dart。

lib/l10n/app_zh.arb（复数用 ICU 语法，other 是必需分支）：

json
{
  "@@locale": "zh",
  "itemCount": "{count, plural, =0{没有项目} other{{count} 个项目}}",
  "@itemCount": { "placeholders": { "count": { "type": "int" } } }
}

使用生成类：

dart
final l10n = AppLocalizations.of(context)!;
Text(l10n.itemCount(3)); // 3 个项目
需求方案
复数ARB 里的 plural，不要用 if (n == 1) 拼字符串
性别用 select 或拆成多个 key，避免在中文里硬套 he/she
日期DateFormat.yMMMd(localeName)，不要手写 yyyy-MM-dd
数字/货币NumberFormat.compact() / NumberFormat.currency(locale: ...)

文案不要拼接

'共 ' + n + ' 项' 在阿拉伯语、俄语（复数形式多）里都不成立。所有可见文案都走 ARB，哪怕一开始只有一种语言。

六、RTL、字体与运行时切换 ​

dart
Directionality(
  textDirection: TextDirection.rtl,
  child: Padding(
    padding: const EdgeInsetsDirectional.only(start: 16, end: 8),
    child: Row(children: [
      const Icon(Icons.chevron_right, matchTextDirection: true),
      Expanded(child: Text('标题')),
    ]),
  ),
)
  • 用 EdgeInsetsDirectional / AlignmentDirectional 代替 left/right，镜像逻辑交给框架。
  • 运行时切换：
dart
MaterialApp(
  locale: _locale, // 由设置页写入
  supportedLocales: AppLocalizations.supportedLocales,
  localizationsDelegates: AppLocalizations.localizationsDelegates,
)

locale 变化会触发重建，AppLocalizations.of(context) 随之返回新语言；测试里可用 tester.binding.platformDispatcher.localeTestValue 模拟系统语言。

CJK 字体与行高 ​

  • 中文行高建议 height: 1.5 ~ 1.6，西文 1.2 ~ 1.4；混排时以中文为准。
  • 指定 fontFamilyFallback 覆盖生僻字与 emoji，避免方框。
  • TextHeightBehavior 可去掉首行顶部与末行底部多余留白，让中英文基线更稳。
问题建议
中文挤在一起height: 1.5，段落用 TextStyle(height: ...)
中英混排基线跳统一 TextBaseline.alphabetic，避免逐段手调

七、无障碍测试与检查清单 ​

dart
testWidgets('余额卡片语义正确', (tester) async {
  final handle = tester.ensureSemantics();
  await tester.pumpWidget(const MyApp());
  expect(tester.getSemantics(find.byType(BalanceCard)),
      matchesSemantics(label: '余额 128.50 元'));
  handle.dispose();
});
检查项通过标准
可点击元素都有语义标签，读屏能说出「做什么」
图片有 semanticLabel 或标记为装饰
字号系统最大字号下无溢出、无遮挡
对比度正文 ≥ 4.5:1，状态不只靠颜色
键盘Tab 顺序合理，焦点可见，可回车触发
多语言最长语言（德语/俄语）下不溢出，RTL 布局正确

dart
import 'package:flutter/material.dart';

// 无障碍与适配演示：语义树 + 动态字号 + RTL。
// 打开系统读屏（TalkBack / VoiceOver）能听到每个节点的朗读内容。
void main() => runApp(const MaterialApp(home: _A11yPage()));

class _A11yPage extends StatefulWidget {
  const _A11yPage({super.key});

  @override
  State<_A11yPage> createState() => _A11yPageState();
}

class _A11yPageState extends State<_A11yPage> {
  double _scale = 1.0;
  bool _rtl = false;
  bool _notify = true;

  @override
  Widget build(BuildContext context) {
    final scheme = Theme.of(context).colorScheme;
    return Directionality(
      textDirection: _rtl ? TextDirection.rtl : TextDirection.ltr,
      child: Scaffold(
        appBar: AppBar(title: const Text('无障碍与适配')),
        body: MediaQuery(
          data: MediaQuery.of(context).copyWith(
            textScaler: TextScaler.linear(_scale),
          ),
          child: ListView(
            padding: const EdgeInsets.all(16),
            children: [
              Text('字号缩放 ${_scale.toStringAsFixed(1)}x · RTL：${_rtl ? '开' : '关'}'),
              Slider(
                value: _scale,
                min: 1,
                max: 2,
                divisions: 4,
                label: '${_scale.toStringAsFixed(1)}x',
                onChanged: (v) => setState(() => _scale = v),
              ),
              SwitchListTile(
                dense: true,
                contentPadding: EdgeInsets.zero,
                title: const Text('RTL 布局（模拟阿拉伯语）'),
                value: _rtl,
                onChanged: (v) => setState(() => _rtl = v),
              ),
              const SizedBox(height: 8),
              // 一个语义节点说完卡片内容；内部图标与数字被排除，避免重复朗读
              Semantics(
                label: '余额 128.50 元，双击查看明细',
                button: true,
                child: ExcludeSemantics(
                  child: Container(
                    padding: const EdgeInsets.all(16),
                    decoration: BoxDecoration(
                      color: scheme.primaryContainer,
                      borderRadius: BorderRadius.circular(16),
                    ),
                    child: Row(
                      children: [
                        Icon(Icons.account_balance_wallet,
                            color: scheme.onPrimaryContainer),
                        const SizedBox(width: 12),
                        Text(
                          '128.50',
                          style: TextStyle(
                            fontSize: 28,
                            color: scheme.onPrimaryContainer,
                          ),
                        ),
                      ],
                    ),
                  ),
                ),
              ),
              const SizedBox(height: 12),
              // 标题 + 副标题 + 开关合并成一个朗读节点
              MergeSemantics(
                child: SwitchListTile(
                  title: const Text('消息提醒'),
                  subtitle: const Text('每 30 分钟汇总一次'),
                  value: _notify,
                  onChanged: (v) => setState(() => _notify = v),
                ),
              ),
              const SizedBox(height: 12),
              // 方向性内边距 + 可镜像图标：切 RTL 后自动镜像
              Container(
                padding: const EdgeInsetsDirectional.only(start: 16, end: 4),
                decoration: BoxDecoration(
                  color: scheme.surfaceContainerHighest,
                  borderRadius: BorderRadius.circular(12),
                ),
                child: Row(
                  children: [
                    const Expanded(child: Text('方向性边距：start 16 / end 4')),
                    Icon(Icons.chevron_right,
                        matchTextDirection: true, color: scheme.primary),
                  ],
                ),
              ),
            ],
          ),
        ),
      ),
    );
  }
}

常见坑 ​

高频踩坑点

  1. 用 Semantics 重复朗读：可见 Text 已进语义树，外面再包 label 会出现两遍；要么 ExcludeSemantics，要么合并。
  2. 图标按钮没有标签：IconButton(icon: Icon(Icons.close)) 读屏只会说「按钮」，必须给 tooltip 或 Semantics(label: '关闭')。
  3. 锁死 textScaler：全局 TextScaler.noScaling 让系统字号设置失效，是明确的无障碍缺陷。
  4. 固定高度容器装文本：大字号下文字被裁切，用 minHeight 与 Flexible 替代。
  5. 只写一种语言的 ARB：后续加语言时到处是硬编码中文，返工成本极高；文案从第一天就走 ARB。
  6. RTL 里用 left/right：阿拉伯语下边距和图标方向全错，改用 EdgeInsetsDirectional 与 matchTextDirection。

课后练习 ​

  1. 语义审计：打开系统读屏，把练习 App 的首页完整走一遍，记录所有「读不出用途」的控件并补齐标签。
  2. 大字号挑战：把系统字号调到最大（或 textScaler: 2.0），逐页检查溢出，至少修复三处固定高度布局。
  3. ARB 迁移：把页面里的中文硬编码抽到 app_zh.arb，加一份 app_en.arb，用 flutter gen-l10n 生成并切换验证。
  4. 复数与日期：实现「N 个项目 / 没有项目」的复数文案，并用 DateFormat 按当前 locale 显示日期。
