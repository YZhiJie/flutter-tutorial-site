桌面界面组件定制 ​

学习目标 ​

学完本章，你将能够：

  • 说清桌面与移动在组件层面的差异：输入设备、密度、焦点、窗口与滚动条
  • 用 Design Token + ThemeExtension 搭一套可换肤、可换密度的组件基础
  • 按组件覆盖主题（按钮、输入框、滚动条、弹层、导航栏），而不是到处写死颜色
  • 为组件补齐 hover、光标、焦点环、右键菜单与键盘触发
  • 用断点实现单栏 / 侧栏 / 双栏自适应，并落地可拖拽分隔面板
  • 设计原生感窗口外壳（自定义标题栏、交通灯、拖拽区）的取舍与风险
  • 用组件库工程化手段（API、目录、文档、golden）保证一致性

定制 ≠ 换皮

桌面组件定制的核心不是"改个颜色"，而是让同一套组件在鼠标、键盘、窗口缩放下都表现得像原生应用。颜色只是其中一层。

一、桌面组件到底差在哪 ​

维度移动端默认桌面端要求
输入触摸、长按鼠标 hover、右键、滚轮、键盘 Tab / Enter
密度48dp 最小点击区更紧凑的行高与留白（VisualDensity.compact）
焦点基本不关心焦点环必须可见，Tab 顺序必须合理
窗口全屏、不可缩放可缩放、有最小尺寸、多窗口/分栏
滚动条默认隐藏常驻或 hover 出现，可拖拽
文案"点击""单击 / 右键 / 快捷键 ⌘K"

先记住一句话：移动端的一切"默认就有"的交互，在桌面上都要显式补。

二、Design Token 与 ThemeExtension ​

不要在组件里写 Color(0xFF3B82F6)。把可变的设计决策收敛成 token，组件只引用语义名：

dart
@immutable
class AppTokens extends ThemeExtension<AppTokens> {
  const AppTokens({required this.brand, required this.gap, required this.radius});

  final Color brand;
  final double gap;
  final double radius;

  @override
  AppTokens copyWith({Color? brand, double? gap, double? radius}) => AppTokens(
        brand: brand ?? this.brand,
        gap: gap ?? this.gap,
        radius: radius ?? this.radius,
      );

  @override
  AppTokens lerp(ThemeExtension<AppTokens>? other, double t) {
    if (other is! AppTokens) return this;
    return AppTokens(
      brand: Color.lerp(brand, other.brand, t)!,
      gap: gap + (other.gap - gap) * t,
      radius: radius + (other.radius - radius) * t,
    );
  }
}

注册与读取：

dart
MaterialApp(
  theme: ThemeData(
    colorSchemeSeed: const Color(0xFF3B82F6),
    extensions: const <ThemeExtension<dynamic>>[AppTokens.standard],
  ),
  home: const HomePage(),
);

// 任意组件内
final t = Theme.of(context).extension<AppTokens>()!;

建议分三层，避免 token 变成第二个大杂烩：

层例子谁用
基础 token#3B82F6、8、14只给语义层
语义 tokenbrand、gap、surface、radius所有组件
组件 tokenbuttonHeight、inputPadding、listRowHeight单个组件内部

lerp 必须实现，主题切换动画（AnimatedTheme）才会平滑过渡。

三、逐组件主题覆盖 ​

ThemeData 里每个组件都有对应的主题类。桌面项目至少要覆盖下面这几类：

组件主题类桌面关注点
按钮FilledButtonThemeData / OutlinedButtonThemeData最小高度、圆角、禁用态对比度
输入框InputDecorationTheme边框、密度、聚焦边框、错误文案位置
滚动条ScrollbarThemeData宽度、thumbVisibility、hover 才显示
弹层PopupMenuThemeData / MenuThemeData阴影、圆角、键盘导航高亮
导航NavigationRailThemeData宽度、标签模式、选中指示
图标IconThemeData尺寸分级（16 / 20 / 24）
dart
ThemeData(
  useMaterial3: true,
  visualDensity: VisualDensity.standard, // 桌面默认，紧凑场景再切 compact
  filledButtonTheme: FilledButtonThemeData(
    style: FilledButton.styleFrom(
      minimumSize: const Size(88, 40),
      shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(10)),
    ),
  ),
  scrollbarTheme: ScrollbarThemeData(
    thumbVisibility: WidgetStatePropertyAll<bool>(true),
    thickness: const WidgetStatePropertyAll<double>(8),
  ),
)

密度不要全局拍死

VisualDensity.compact 适合工具型桌面应用，但会让触屏设备点击区过小。正确做法是按输入能力切换：检测到桌面/鼠标（defaultTargetPlatform 或 kIsWeb + 指针类型）再用紧凑密度。

四、桌面交互：hover、光标、焦点、右键 ​

一个"像桌面"的按钮至少要有四种状态：默认、hover、focus、pressed。InkWell 只解决水波纹，hover 与焦点环要自己做：

dart
Focus(
  onFocusChange: (v) => setState(() => _focused = v),
  onKeyEvent: (node, event) {
    if (event is KeyDownEvent &&
        (event.logicalKey == LogicalKeyboardKey.enter ||
            event.logicalKey == LogicalKeyboardKey.space)) {
      widget.onPressed();
      return KeyEventResult.handled;
    }
    return KeyEventResult.ignored;
  },
  child: MouseRegion(
    cursor: SystemMouseCursors.click,
    onEnter: (_) => setState(() => _hovered = true),
    onExit: (_) => setState(() => _hovered = false),
    child: GestureDetector(
      onTap: widget.onPressed,
      onSecondaryTapDown: (details) => _showContextMenu(details.globalPosition),
      child: AnimatedContainer(/* 背景随 _hovered 变化，边框随 _focused 加粗 */),
    ),
  ),
)

配套要点：

  • 右键菜单：showMenu + RelativeRect.fromRect(globalPosition & Size(1, 1), ...)，Esc 关闭是内置行为
  • 光标：可点击 SystemMouseCursors.click、可拖拽 resizeColumn、文本 text、禁用 basic
  • Tab 顺序：用 FocusTraversalGroup 包住逻辑分组，必要时 FocusTraversalOrder
  • 快捷键：Shortcuts + Actions，先判断 FocusManager.instance.primaryFocus 是否在输入框，避免 ⌘S 被误吃

五、自适应布局：断点、双栏与可拖拽分隔 ​

沿用 Material 3 的断点，但判断依据是可用宽度，不是设备类型：

宽度形态典型内容
< 600单栏列表与详情上下堆叠
600 ~ 840侧栏 + 单栏NavigationRail + 内容区
>= 840双栏列表 + 详情，或主区 + 辅助面板
dart
LayoutBuilder(
  builder: (context, constraints) {
    final width = constraints.maxWidth;
    final compact = width < 600;
    final expanded = width >= 840;
    return compact
        ? _singleColumn()
        : _wideLayout(expanded, width);
  },
)

可拖拽分隔面板的关键是夹紧宽度，否则用户能把一侧拖成 0：

dart
final leftWidth = (width * _split).clamp(200.0, width - 320.0);

MouseRegion(
  cursor: SystemMouseCursors.resizeColumn,
  child: GestureDetector(
    onHorizontalDragUpdate: (d) => setState(() {
      _split = (_split + d.delta.dx / width).clamp(0.22, 0.6);
    }),
    child: Container(width: 6, color: outlineVariant),
  ),
)

展开态做"列表 + 详情"，而不是把手机布局拉宽——这是桌面适配里最常见的偷懒。

六、窗口外壳：标题栏与交通灯 ​

真正要"像原生应用"，最后一步是窗口外壳。三种做法：

方案适用代价
保留系统标题栏绝大多数业务应用视觉与设计稿不一致，但最稳
隐藏系统标题栏 + 自绘设计驱动型产品需自行实现拖拽、双击最大化、关闭/最小化按钮
只内嵌交通灯（macOS）想要沉浸式标题区平台差异大，Windows 需另做

要点（以 window_manager 为例）：

  • 用 setTitleBarStyle(TitleBarStyle.hidden) 隐藏系统栏，自己画标题栏
  • 自绘标题栏必须提供拖拽区：DraggableRegion（macOS）或 windowManager.startDragging()（跨平台）
  • 双击标题栏最大化、Esc 退出全屏、窗口最小尺寸这些"免费功能"在自绘后都要补
  • 交通灯位置用 setTrafficLightPosition 调整，别让按钮压住红绿灯
  • 关闭按钮要拦截未保存状态：setPreventClose(true) + onWindowClose

自绘标题栏是体验债

一旦自绘，就要在 macOS / Windows / Linux 三套拖拽、双击、吸附、多显示器缩放行为上持续维护。没有明确设计要求时，保留系统标题栏更划算。

七、组件库工程化 ​

组件一旦超过 20 个，就必须当成内部产品来管：

  • API 收敛：variant（primary/secondary/danger）+ size（sm/md）+ state 三轴，不要每个页面传一堆 style:
  • 目录分层：design_system/tokens、design_system/components、design_system/layout，业务层只 import 组件，不 import token
  • 单一入口：design_system/design_system.dart 统一导出，禁止深层 import
  • 文档化：Widgetbook 或本仓库这种"示例 App"集中展示所有变体
  • 视觉回归：关键组件的 golden 测试锁住 hover / focus / disabled 三态
dart
enum ButtonVariant { primary, secondary, danger }

ButtonStyle styleFor(ButtonVariant v, AppTokens t, ColorScheme scheme) {
  return switch (v) {
    ButtonVariant.primary => FilledButton.styleFrom(backgroundColor: t.brand),
    ButtonVariant.secondary => OutlinedButton.styleFrom(side: BorderSide(color: t.brand)),
    ButtonVariant.danger => FilledButton.styleFrom(backgroundColor: scheme.error),
  };
}

dart
import 'package:flutter/material.dart';

/// 桌面界面组件定制最小示例：
/// 1) 用 ThemeExtension 承载自定义 token（颜色 / 间距 / 圆角 / 控件高度）
/// 2) 按钮补齐 hover、光标与焦点环
/// 3) 用 LayoutBuilder 断点切换单栏 / 侧栏 / 双栏
void main() => runApp(const DeskUiApp());

class DeskUiApp extends StatelessWidget {
  const DeskUiApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(
        colorSchemeSeed: const Color(0xFF3B82F6),
        extensions: const <ThemeExtension<dynamic>>[AppTokens.standard],
      ),
      home: const DeskUiHome(),
    );
  }
}

@immutable
class AppTokens extends ThemeExtension<AppTokens> {
  const AppTokens({
    required this.brand,
    required this.gap,
    required this.radius,
  });

  static const AppTokens standard =
      AppTokens(brand: Color(0xFF3B82F6), gap: 16, radius: 14);

  final Color brand;
  final double gap;
  final double radius;

  @override
  AppTokens copyWith({Color? brand, double? gap, double? radius}) => AppTokens(
        brand: brand ?? this.brand,
        gap: gap ?? this.gap,
        radius: radius ?? this.radius,
      );

  @override
  AppTokens lerp(ThemeExtension<AppTokens>? other, double t) {
    if (other is! AppTokens) return this;
    return AppTokens(
      brand: Color.lerp(brand, other.brand, t)!,
      gap: gap + (other.gap - gap) * t,
      radius: radius + (other.radius - radius) * t,
    );
  }
}

class DeskUiHome extends StatefulWidget {
  const DeskUiHome({super.key});
  @override
  State<DeskUiHome> createState() => _DeskUiHomeState();
}

class _DeskUiHomeState extends State<DeskUiHome> {
  bool _compact = false;

  @override
  Widget build(BuildContext context) {
    final tokens = AppTokens.standard
        .copyWith(gap: _compact ? 8 : 16, radius: _compact ? 6 : 14);
    return Theme(
      data: Theme.of(context).copyWith(
        extensions: <ThemeExtension<dynamic>>[tokens],
      ),
      child: Scaffold(
        appBar: AppBar(
          title: const Text('桌面界面组件定制'),
          actions: <Widget>[
            Padding(
              padding: const EdgeInsets.only(right: 12),
              child: FilterChip(
                label: const Text('紧凑密度'),
                selected: _compact,
                onSelected: (v) => setState(() => _compact = v),
              ),
            ),
          ],
        ),
        body: LayoutBuilder(
          builder: (context, constraints) {
            final compact = constraints.maxWidth < 600;
            final expanded = constraints.maxWidth >= 840;
            final t = Theme.of(context).extension<AppTokens>()!;
            return Padding(
              padding: EdgeInsets.all(t.gap),
              child: Column(
                crossAxisAlignment: CrossAxisAlignment.start,
                children: <Widget>[
                  Text(
                    '宽度 ${constraints.maxWidth.toStringAsFixed(0)} · '
                    '${compact ? '单栏' : expanded ? '双栏' : '侧栏 + 单栏'}',
                    style: Theme.of(context).textTheme.bodySmall,
                  ),
                  SizedBox(height: t.gap),
                  Wrap(
                    spacing: t.gap,
                    runSpacing: t.gap,
                    children: <Widget>[
                      DeskButton(
                        label: '主操作',
                        primary: true,
                        onPressed: () {},
                      ),
                      DeskButton(label: '次操作', onPressed: () {}),
                    ],
                  ),
                  SizedBox(height: t.gap),
                  Expanded(
                    child: compact
                        ? _panel(context, '内容区：拖动窗口或缩窄浏览器，断点会自动切换布局')
                        : Row(
                            children: <Widget>[
                              SizedBox(
                                width: 220,
                                child: _panel(context, '侧栏：模块列表'),
                              ),
                              SizedBox(width: t.gap),
                              if (expanded) ...<Widget>[
                                Expanded(child: _panel(context, '左栏：列表')),
                                SizedBox(width: t.gap),
                                Expanded(child: _panel(context, '右栏：详情')),
                              ] else
                                Expanded(child: _panel(context, '内容区')),
                            ],
                          ),
                  ),
                ],
              ),
            );
          },
        ),
      ),
    );
  }

  Widget _panel(BuildContext context, String text) {
    final t = Theme.of(context).extension<AppTokens>()!;
    return Container(
      alignment: Alignment.center,
      padding: EdgeInsets.all(t.gap),
      decoration: BoxDecoration(
        color: Theme.of(context).colorScheme.surfaceContainerHighest,
        borderRadius: BorderRadius.circular(t.radius),
      ),
      child: Text(text, textAlign: TextAlign.center),
    );
  }
}

class DeskButton extends StatefulWidget {
  const DeskButton({
    super.key,
    required this.label,
    required this.onPressed,
    this.primary = false,
  });

  final String label;
  final VoidCallback onPressed;
  final bool primary;

  @override
  State<DeskButton> createState() => _DeskButtonState();
}

class _DeskButtonState extends State<DeskButton> {
  bool _hovered = false;
  bool _focused = false;

  @override
  Widget build(BuildContext context) {
    final scheme = Theme.of(context).colorScheme;
    final t = Theme.of(context).extension<AppTokens>()!;
    final base = widget.primary ? t.brand : scheme.surfaceContainerHighest;
    final fg = widget.primary ? Colors.white : scheme.onSurface;
    return Focus(
      onFocusChange: (v) => setState(() => _focused = v),
      child: MouseRegion(
        cursor: SystemMouseCursors.click,
        onEnter: (_) => setState(() => _hovered = true),
        onExit: (_) => setState(() => _hovered = false),
        child: GestureDetector(
          onTap: widget.onPressed,
          child: AnimatedContainer(
            duration: const Duration(milliseconds: 120),
            height: 40,
            padding: const EdgeInsets.symmetric(horizontal: 18),
            alignment: Alignment.center,
            decoration: BoxDecoration(
              color: _hovered
                  ? Color.alphaBlend(fg.withValues(alpha: 0.1), base)
                  : base,
              borderRadius: BorderRadius.circular(t.radius),
              border: Border.all(
                color: _focused ? scheme.primary : scheme.outlineVariant,
                width: _focused ? 2 : 1,
              ),
            ),
            child: Text(widget.label, style: TextStyle(color: fg)),
          ),
        ),
      ),
    );
  }
}

常见坑 ​

高频踩坑点

  1. 颜色写死在组件里：换品牌色时漏改十几处。所有可变样式必须走 token。
  2. 只做 hover 不做 focus：键盘用户完全无法感知当前焦点，无障碍直接不合格。
  3. 焦点环被裁掉：外层 ClipRRect / ListView 的 clipBehavior 把 2px 焦点环切掉一半。
  4. 用平台判断代替断点：iPad 分屏、桌面小窗口都会失配，布局只认可用宽度。
  5. 拖拽分隔不夹紧：用户能把一侧拖到 0 宽，布局直接溢出。
  6. 自绘标题栏忘拖拽区：窗口变成"不能移动"的假桌面应用。
  7. 组件 API 透传 ThemeData：业务层开始各自传 style，组件库形同虚设。

课后练习 ​

  1. Token 换肤：把示例里的品牌色、圆角、间距抽成 AppTokens，做 3 套预设并支持运行时切换。
  2. 桌面按钮：实现带 hover、focus、pressed、disabled 四态的按钮，并补 golden 测试。
  3. 可拖拽双栏：在 840px 以上实现列表 + 详情双栏，分隔条可拖拽并夹紧最小宽度。
  4. 窗口外壳：用 window_manager 隐藏系统标题栏，自绘标题栏并实现拖拽、双击最大化、关闭拦截。
  5. 组件文档：接 Widgetbook，把按钮的 3 种 variant × 3 种尺寸 × 4 种状态全部展示出来。
