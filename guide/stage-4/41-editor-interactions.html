复杂交互与编辑器：拖拽、画布、撤销重做 ​

学习目标 ​

学完本章，你将能够：

  • 实现同列表与跨列表拖拽排序，处理插入位置、拖拽预览与自动滚动
  • 用世界坐标 / 屏幕坐标变换实现缩放与平移，并让缩放围绕指针焦点进行
  • 做框选、多选、命中测试与视口裁剪，避免画布节点变多后掉帧
  • 用命令模式实现撤销 / 重做，理解事务与批量合并的边界
  • 用 Shortcuts / Actions / CallbackShortcuts 管理快捷键作用域
  • 实现命令面板，并在打开面板时捕获正确的上下文（焦点、选区、文档）
  • 知道什么时候该用成熟编辑器内核，而不是自己从零造一个

交互编辑器的三大基础

坐标（屏幕 ↔ 世界）、状态变更（命令 + 历史）、输入路由（焦点 + 快捷键）。把这三件事拆开，拖拽、画布、命令面板都只是组合。

一、拖拽排序 ​

同列表排序 ​

最省事的是 ReorderableListView：

dart
ReorderableListView.builder(
  itemCount: items.length,
  onReorder: (oldIndex, newIndex) {
    if (oldIndex < newIndex) newIndex -= 1;
    setState(() {
      final item = items.removeAt(oldIndex);
      items.insert(newIndex, item);
      history.push(MoveCommand(oldIndex, newIndex));
    });
  },
  itemBuilder: (context, index) => ListTile(title: Text(items[index])),
);

onReorder 的 newIndex 是「插入之前的索引」，当 oldIndex < newIndex 时必须减一，否则会差一位。

跨列表与自定义落点 ​

需要跨列移动时，用 Draggable + DragTarget 自己控制落点：

dart
Draggable<String>(
  data: card.id,
  feedback: DragPreview(card: card),
  childWhenDragging: Opacity(opacity: 0.35, child: cardTile),
  child: cardTile,
)

DragTarget<String>(
  onWillAcceptWithDetails: (_) => true,
  onAcceptWithDetails: (details) => moveCard(details.data, column, index),
  builder: (context, candidate, rejected) => highlight(candidate.isNotEmpty),
)

关键设计：

问题做法
插入到哪个位置在卡片之间放细缝 DragTarget，落点即索引；列级 target 负责追加到末尾
同列移动索引偏移原索引在落点之前时，目标索引减一
拖拽预览feedback 固定尺寸，避免跟着手指变形
触摸端误触用 LongPressDraggable 或设置 delay，避免一滑就拖
自动滚动在 onDragUpdate 里判断指针是否进入列顶 / 底 56px，驱动 ScrollController

自动滚动的核心不是「滚动」，而是指针位置到列的局部坐标：

dart
final box = columnKey.currentContext!.findRenderObject() as RenderBox;
final local = box.globalToLocal(details.globalPosition);
if (local.dy < 56) controller.jumpTo(max(0, controller.offset - 10));
else if (local.dy > box.size.height - 56) {
  controller.jumpTo(min(controller.position.maxScrollExtent, controller.offset + 10));
}

桌面端还可以用 DragTarget.onMove 做更细的悬停反馈；触摸端要注意滚动与拖拽的手势竞争。

二、坐标变换与缩放平移 ​

画布一定要区分两套坐标：

  • 世界坐标：节点真实位置，不随视口变化。
  • 屏幕坐标：world * scale + offset。
dart
Offset toScreen(Offset world) => world * scale + offset;
Offset toWorld(Offset screen) => (screen - offset) / scale;

CustomPainter 里用同一套变换：

dart
canvas.save();
canvas.translate(offset.dx, offset.dy);
canvas.scale(scale);
// 这里按世界坐标绘制节点与连线
canvas.restore();

围绕焦点缩放 ​

用户滚轮缩放时，要保证指针下的世界点不动：

dart
void zoomAt(double factor, Offset focal) {
  final world = (focal - offset) / scale;
  scale = (scale * factor).clamp(0.4, 3.0);
  offset = focal - world * scale;
}

顺序不能反：先记录焦点对应的世界坐标，再改 scale，最后反推 offset。

用 InteractiveViewer 还是自己写 ​

场景建议
只是查看 / 缩放图片、PDF 页InteractiveViewer，省掉大部分手势细节
需要节点拖拽、框选、吸附、撤销自己管 scale + offset，避免手势冲突
复杂编辑器自研变换 + 成熟交互内核（如 super_editor）

三、框选、多选与命中测试 ​

命中测试的顺序是从上到下，谁在视觉最上层谁先响应：

dart
Node? hitTest(Offset screen) {
  final world = toWorld(screen);
  for (final node in nodes.reversed) {
    if (node.rect.contains(world)) return node;
  }
  return null;
}

框选：

dart
final rect = Rect.fromPoints(start, current);
final worldRect = Rect.fromPoints(toWorld(rect.topLeft), toWorld(rect.bottomRight));
final selected = nodes.where((n) => n.rect.overlaps(worldRect)).toList();

多选交互约定：

  • 普通点击：替换选区。
  • Shift / Ctrl 点击：追加或取消。
  • 在空白处点击：清空选区。
  • 框选：只选与选框相交的节点；需要「完全包含」时改用 worldRect.contains(node.rect.topLeft) && ...。
  • 多选后拖动：所有选中节点按同一 delta 移动，按世界坐标增量 delta / scale 计算。

示例 mini_canvas_demo.dart 同时实现了命中测试、框选、多选高亮、批量删除与恢复。

四、视口裁剪 ​

节点多起来后，绘制与命中测试都会变慢。两层裁剪：

  1. 绘制裁剪：只画与视口相交的节点。
  2. 命中裁剪：先把屏幕点转世界坐标，再按节点包围盒判断。
dart
final visibleWorld = Rect.fromPoints(toWorld(Offset.zero), toWorld(size.bottomRight));
for (final node in nodes) {
  if (!node.rect.inflate(4).overlaps(visibleWorld)) continue;
  drawNode(node);
}

补充手段：

  • ClipRect / clipBehavior 保证内容不出界。
  • RepaintBoundary 把静态背景与动态节点分开，减少重绘。
  • 大量节点时按空间网格（quadtree / 网格哈希）索引，避免每次全量遍历。
  • 连线也要裁剪，否则一条长线仍然会触发大范围绘制。

五、命令模式与撤销重做 ​

不要保存「整个状态快照」做撤销，改成可逆命令：

dart
class MoveCardCommand {
  MoveCardCommand({required this.id, required this.from, required this.fromIndex,
      required this.to, required this.toIndex});

  final String id;
  final String from;
  final int fromIndex;
  final String to;
  final int toIndex;

  void apply(Map<String, List<String>> columns) {
    columns[from]?.remove(id);
    columns[to]?.insert(toIndex, id);
  }

  void revert(Map<String, List<String>> columns) {
    columns[to]?.remove(id);
    columns[from]?.insert(fromIndex, id);
  }
}

历史栈：

dart
void run(Command command) {
  command.apply(model);
  undoStack.add(command);
  redoStack.clear();
}

void undo() {
  if (undoStack.isEmpty) return;
  final command = undoStack.removeLast();
  command.revert(model);
  redoStack.add(command);
}

事务与批量合并 ​

一次用户操作包含多条命令时，用组合命令：

dart
class BatchCommand {
  BatchCommand(this.parts);
  final List<Command> parts;

  void apply() => parts.forEach((c) => c.apply());
  void revert() => parts.reversed.forEach((c) => c.revert());
}

规则：

  • 一次撤销 = 一次用户心智操作。批量归档 5 张卡片算一步，不是五步。
  • apply / revert 必须幂等且对称。索引要 clamp，删除前要判断存在。
  • 合并输入：连续拖拽或滑块调整可以在 300~500ms 内合并为一条命令，避免历史里塞满中间态。
  • 历史有上限：大型文档按内存预算截断，或把早期历史持久化到磁盘。
  • 命令要可序列化（协作 / 持久化场景），否则无法回放与多人合并。

六、快捷键作用域与命令面板 ​

Shortcuts / Actions 比硬编码 RawKeyboardListener 更稳 ​

dart
Shortcuts(
  shortcuts: <ShortcutActivator, Intent>{
    const SingleActivator(LogicalKeyboardKey.keyS, control: true): const SaveIntent(),
    const SingleActivator(LogicalKeyboardKey.keyZ, meta: true): const UndoIntent(),
  },
  child: Actions(
    actions: <Type, Action<Intent>>{
      SaveIntent: CallbackAction<SaveIntent>(onInvoke: (_) => save()),
      UndoIntent: CallbackAction<UndoIntent>(onInvoke: (_) => undo()),
    },
    child: Focus(autofocus: true, child: editor),
  ),
)

作用域规则：

  • 快捷键只在焦点位于该子树内时生效，这就是「编辑器内 Ctrl+S 有效，焦点移到搜索框就失效」的原因。
  • 全局快捷键放在更外层，局部快捷键放内层；内层优先。
  • 文本输入框里的按键不要被编辑器抢走，必要时用 Shortcuts 的作用域或 TextField 的 onSubmitted 区分。
  • 触摸端没有键盘，所有命令必须有可见入口（工具栏 / 命令面板）。

简化场景可以用 CallbackShortcuts 直接绑回调；需要按意图分发、拦截、优先级时用 Shortcuts + Actions + Intent。

命令面板 ​

命令面板的价值是「可搜索 + 可发现 + 上下文感知」。最小实现：

dart
void openPalette() {
  final context = captureContext(); // 焦点、选区、文档 id
  showDialog(
    context: context,
    builder: (_) => CommandPalette(
      commands: registry,
      editorFocused: context.editorFocused,
      onRun: (id) => runCommand(id, context),
    ),
  );
}

要点：

  • 打开时捕获上下文。对话框会抢走焦点，不能在执行时再问「当前编辑器有没有焦点」。
  • 无上下文命令置灰。没有选中节点时「删除选中」应禁用，而不是执行一个空操作。
  • 搜索只匹配标题与关键词，不要扫全量正文；结果按使用频率与最近使用排序。
  • 快捷键写在面板里，让用户顺便学习快捷键。
  • 命令注册表集中管理，工具栏、菜单、快捷键、面板共用同一套命令，避免四份实现。

示例 command_palette_demo.dart 用 FocusNode.hasFocus 记录编辑器作用域，并把「打开面板时是否有编辑器焦点」传给对话框。

七、性能与验收 ​

检查项通过标准
拖拽帧率长列表滚动 + 拖拽时稳定 60 / 120fps，无明显掉帧

坐标变换缩放围绕焦点，平移与缩放不漂移

dart
import 'package:flutter/material.dart';
import 'package:flutter/services.dart';

/// 拖拽排序 + 命令模式撤销/重做 + 快捷键的最小闭环。
void main() => runApp(const InteractionLabApp());

class InteractionLabApp extends StatelessWidget {
  const InteractionLabApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.deepPurple, useMaterial3: true),
      home: const ReorderHome(),
    );
  }
}

class _MoveItemCommand {
  _MoveItemCommand({required this.from, required this.to});

  final int from;
  final int to;

  String get label => '移动第 ${from + 1} 项 → 第 ${to + 1} 位';
}

class ReorderHome extends StatefulWidget {
  const ReorderHome({super.key});

  @override
  State<ReorderHome> createState() => _ReorderHomeState();
}

class _ReorderHomeState extends State<ReorderHome> {
  final List<String> _items = <String>['设计评审', '接口实现', '组件联调', '验收测试', '发布复盘'];
  final List<_MoveItemCommand> _undo = <_MoveItemCommand>[];
  final List<_MoveItemCommand> _redo = <_MoveItemCommand>[];
  String _status = '拖动卡片调整顺序，或用 Ctrl/⌘ + Z 撤销。';

  void _applyMove(_MoveItemCommand command, {required bool forward}) {
    final source = forward ? command.from : command.to;
    final target = forward ? command.to : command.from;
    final item = _items.removeAt(source);
    _items.insert(target.clamp(0, _items.length), item);
  }

  void _move(int from, int rawTo) {
    var to = rawTo;
    if (from < to) to--;
    if (from == to) return;
    final command = _MoveItemCommand(from: from, to: to);
    setState(() {
      _applyMove(command, forward: true);
      _undo.add(command);
      _redo.clear();
      _status = command.label;
    });
  }

  void _undoAction() {
    if (_undo.isEmpty) return;
    final command = _undo.removeLast();
    setState(() {
      _applyMove(command, forward: false);
      _redo.add(command);
      _status = '撤销：${command.label}';
    });
  }

  void _redoAction() {
    if (_redo.isEmpty) return;
    final command = _redo.removeLast();
    setState(() {
      _applyMove(command, forward: true);
      _undo.add(command);
      _status = '重做：${command.label}';
    });
  }

  @override
  Widget build(BuildContext context) {
    return CallbackShortcuts(
      bindings: <ShortcutActivator, VoidCallback>{
        const SingleActivator(LogicalKeyboardKey.keyZ, control: true): _undoAction,
        const SingleActivator(LogicalKeyboardKey.keyZ, meta: true): _undoAction,
        const SingleActivator(LogicalKeyboardKey.keyZ, control: true, shift: true):
            _redoAction,
        const SingleActivator(LogicalKeyboardKey.keyZ, meta: true, shift: true):
            _redoAction,
      },
      child: Focus(
        autofocus: true,
        child: Scaffold(
          appBar: AppBar(title: const Text('拖拽排序与撤销重做')),
          body: Column(
            children: <Widget>[
              Padding(
                padding: const EdgeInsets.all(12),
                child: Row(
                  children: <Widget>[
                    FilledButton.tonalIcon(
                      onPressed: _undo.isEmpty ? null : _undoAction,
                      icon: const Icon(Icons.undo),
                      label: Text('撤销 (${_undo.length})'),
                    ),
                    const SizedBox(width: 8),
                    FilledButton.tonalIcon(
                      onPressed: _redo.isEmpty ? null : _redoAction,
                      icon: const Icon(Icons.redo),
                      label: Text('重做 (${_redo.length})'),
                    ),
                  ],
                ),
              ),
              Padding(
                padding: const EdgeInsets.symmetric(horizontal: 12),
                child: Text(
                  _status,
                  style: Theme.of(context).textTheme.bodySmall,
                ),
              ),
              const SizedBox(height: 8),
              Expanded(
                child: ListView.builder(
                  padding: const EdgeInsets.fromLTRB(12, 0, 12, 12),
                  itemCount: _items.length * 2 + 2,
                  itemBuilder: (context, index) {
                    if (index == _items.length * 2 + 1) {
                      return DragTarget<int>(
                        onAcceptWithDetails: (details) =>
                            _move(details.data, _items.length),
                        builder: (context, candidate, rejected) => Container(
                          height: 32,
                          alignment: Alignment.center,
                          color: candidate.isNotEmpty
                              ? Theme.of(context).colorScheme.primary.withValues(alpha: 0.15)
                              : null,
                          child: const Text('拖到这里放到末尾'),
                        ),
                      );
                    }
                    if (index.isEven) {
                      final insertIndex = index ~/ 2;
                      return DragTarget<int>(
                        onAcceptWithDetails: (details) =>
                            _move(details.data, insertIndex),
                        builder: (context, candidate, rejected) => Container(
                          height: 10,
                          margin: const EdgeInsets.symmetric(vertical: 1),
                          color: candidate.isNotEmpty
                              ? Theme.of(context).colorScheme.primary.withValues(alpha: 0.35)
                              : Colors.transparent,
                        ),
                      );
                    }
                    final itemIndex = index ~/ 2;
                    final card = Card(
                      margin: EdgeInsets.zero,
                      child: ListTile(
                        leading: CircleAvatar(
                          radius: 14,
                          child: Text('${itemIndex + 1}'),
                        ),
                        title: Text(_items[itemIndex]),
                        trailing: const Icon(Icons.drag_indicator),
                      ),
                    );
                    return Draggable<int>(
                      data: itemIndex,
                      feedback: Material(
                        elevation: 6,
                        child: SizedBox(width: 260, child: card),
                      ),
                      childWhenDragging: Opacity(opacity: 0.3, child: card),
                      child: card,
                    );
                  },
                ),
              ),
              Padding(
                padding: const EdgeInsets.all(12),
                child: Text(
                  'Ctrl/⌘ + Z 撤销 · Ctrl/⌘ + Shift + Z 重做 · 每次移动生成一条命令',
                  style: Theme.of(context).textTheme.bodySmall,
                ),
              ),
            ],
          ),
        ),
      ),
    );
  }
}

常见坑 ​

高频踩坑点

  1. onReorder 忘记减一：同列表向下拖动永远错一位。
  2. 只在 onAccept 处理落点：拖动过程中没有插入指示，用户不知道会插到哪。
  3. 自动滚动只看全局坐标：多列布局里滚动错列；必须转成列的局部坐标。
  4. 缩放后坐标不换算：拖拽 delta 直接当成世界位移，缩放 2 倍后移动速度翻倍。
  5. 缩放中心漂移：先改 scale 再算焦点世界坐标，画面会跳。
  6. 框选只判中心点：大节点只碰到边缘时选不中；应判矩形相交。
  7. 撤销存整份快照：文档一大就内存爆炸，且无法做事务合并。
  8. apply / revert 不对称：撤销后索引错位，历史越用越乱。
  9. 快捷键绑在页面根节点：文本框输入被抢，或者对话框打开后仍然触发。
  10. 命令面板执行时再问上下文：对话框已经抢走焦点，编辑器命令全部失效。
  11. 节点全量绘制：几千个节点全画，缩放到局部也掉帧。
  12. 自己从零造富文本内核：选区、输入法、协作、撤销的复杂度远超预期，优先评估成熟内核。

课后练习 ​

  1. 同列表排序：用 ReorderableListView 实现并补上索引减一的单元测试。
  2. 跨列拖拽：给看板加「拖到列底部追加」与「拖到卡片间隙插入」两种落点，验证撤销后的索引。
  3. 自动滚动调参：把触发区从 56px 改成 80px，并处理「拖拽离开列」立即停止滚动。
  4. 焦点缩放：实现滚轮围绕指针缩放，再用双指手势验证平移与缩放不漂移。
  5. 框选模式：增加「完全包含」与「相交」两种框选策略，并在 UI 上切换。
  6. 事务合并：连续拖动同一张卡片 500ms 内的多次移动合并为一条命令。
  7. 命令面板：增加最近使用排序与快捷键展示，无选中节点时禁用删除命令。
  8. 视口裁剪：给迷你画布加 200 个节点，用 RepaintBoundary 与网格索引对比帧耗时。
