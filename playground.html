在线运行示例 ​

本站所有可交互示例均由 <DartPad> 组件渲染，底层基于官方 DartPad，支持完整的 Flutter Web 运行环境。你可以直接在编辑器里修改代码，点击 Run 查看结果。

1. 内置示例（sample） ​

Flutter 官方计数器示例，加载后自动运行：

DartPad 运行环境将在滚动到此处时加载…
md
<DartPad sample="counter" run :height="520" />

2. 注册表示例（example） ​

教程中反复使用的示例统一注册在 docs/.vitepress/theme/examples.ts 中，通过 key 引用：

DartPad 运行环境将在滚动到此处时加载…
md
<DartPad example="dart-async" run />

3. 内嵌短代码（code） ​

适合一次性短片段：

DartPad 运行环境将在滚动到此处时加载…
md
<DartPad code="void main() { print('Hello, Flutter!'); }" run :height="360" />

4. Gist 示例（id） ​

先在 dartpad.dev 编写并保存为 GitHub Gist，再引用其 ID：

md
<DartPad id="你的GistId" />

组件参数一览 ​

参数类型默认值说明
idstring—DartPad Gist ID
samplestring—内置示例名（如 counter）
examplestring—examples.ts 注册表中的 key
codestring—内嵌 Dart 源码（短代码）
heightnumber | string480运行区高度
runbooleanfalse加载后自动运行
theme'auto' | 'light' | 'dark''auto'默认跟随站点明暗主题

移动端体验

窄屏设备上组件会降级为「在 DartPad 中打开」链接，避免小屏 iframe 操作不便。
